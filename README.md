# Mercenary (머서너리)

용병을 고용해 주변에 배치하며 싸우는 뱀서류 멀티플레이(6인 이상) 게임.

## 구조

- `shared/` - 서버·클라이언트가 함께 쓰는 규칙과 프로토콜 (TypeScript)
- `server/` - 전투를 계산하는 권위 서버 (Node.js + ws, 초당 20틱)
- `client/` - 화면과 입력 (PixiJS + Vite). 입력만 보내고 서버 결과를 그린다

## 실행

```sh
npm install
npm run dev:server   # ws://localhost:8080
npm run dev:client   # http://localhost:5173
```

접속하면 로비가 나온다. 같은 서버에 여러 탭으로 접속하면 멀티플레이를 확인할 수 있다.
서버 포트는 환경 변수 `PORT`(기본 8080)로 지정한다. 개발 서버(5173)는 `/ws`를 게임 서버(8080)로 넘겨 준다. 다른 서버에 붙으려면 `?server=ws://호스트:포트/ws`.
`?name=이름`을 붙여 열면 로비를 건너뛰고 바로 빠른 시작하고, `?name=이름&room=코드`면 그 방에 바로 참가한다(링크 공유·테스트용).
조작: WASD/방향키 이동, 마우스로 조준, 마우스 왼쪽 버튼을 누르고 있으면 발사, 스페이스는 무기별 스킬, 우클릭은 기병 돌격 지시, 캠프 근처에서 1~3 키로 용병 고용·Shift+1~5로 해고, 레벨업 카드는 Z/X/C, 무기 전환은 Q 또는 마우스 휠.

## 규칙 요약

- **적의 공격은 모션이 있다.** 닿는다고 피해를 입지 않고, 공격 예비 동작(빨간 부채꼴/선 표시)이 끝나는 순간 그 범위 안에 있으면 맞는다. 피하면 안 맞는다.
- **병종**은 기병·창병·궁병·검방병·둔기병 5종이 적과 용병에 모두 있고, 용병에는 **마법사**가 하나 더 있다(아래). 상성은 "몇 % 강하다"가 아니라 구체적인 규칙이다. 수치는 `shared/src/rules.ts`.
  - **검방병**: 몸 체력과 별개로 **방패 체력**이 있고, **정면(좌우 70도)에서 오는 공격만** 방패가 흡수한다. 옆·뒤에서 맞으면 방패를 무시한다. 방패에는 화살 25% · 기병 돌격 50% · 창 60% · 검 100% · **철퇴 300%**로 들어가 궁수에게는 오래 버티고 둔기병에게는 취약하다. 방패가 깨지면 8초 뒤 재생되고, 깨진 동안은 정면 흡수가 사라질 뿐 별도의 취약 배율은 없다(짧은 사거리와 낮은 공격력이 약점).
  - **둔기병**: 방패 특화(300%)와 작은 **범위 공격**(맞힌 대상 주변 46px의 다른 적에게 절반 피해).
  - **기병**: (용병 공격 범위는 창병처럼 앞으로 뻗은 직사각형이지만 사거리 53으로 훨씬 짧고 반폭 15(`CAV_HALF_WIDTH`).) 움직이면 속도가 점점 붙어(약 2초에 최대) 공격에 **속도에 비례한 돌격 피해**가 더해진다. 공격하면 속도를 잃는다. 옆·뒤로 돌아 방패를 우회하고 궁병·둔기병을 노린다.
  - **카운터 표시**: 달려오는 기병이 창에 먼저 맞아 카운터를 입을 때(적 창병이 아군 기병을 맞히는 경우 포함) 맞은 자리에 주황 충격 고리와 금속음이 나고, 내 유닛이 관련되면 `카운터! N` 숫자가 뜬다(`EVT_COUNTER`). 근접 반사 카드가 되돌려주는 피해는 `반사 N`(`EVT_REFLECT`)로 구분된다. 창병 카운터를 맞은 기병은 **뒤로 튕겨 난다**(돌격 피해가 클수록 멀리, `counterKnock`). 적 기병도 아군 기병처럼 짧은 직사각형으로 찌른다(사거리 46).
  - **창병**: 돌격 피해를 받지 않고, **기병이 돌격 피해를 넣기 전에 창에 맞으면 기병이 속도(가속)를 잃고 쌓아 둔 돌격 피해만큼 카운터를 입는다**(속도가 `0.1` 이상 붙어 있을 때, 멈춘 기병은 해당 없음). 돌격이 이미 들어간 뒤에는 되돌려주지 않는다. 근접 사거리가 가장 길다(창병 > 둔기병 > 검방병).
  - **궁병**: 사거리가 길지만 방패 정면에는 거의 막힌다.
- **피해 숫자**: 내 주인공·용병이 적에게 준 피해는 흰 숫자, **치명타는 크고 굵은 금색 숫자(`112!`)**, 적 방패가 흡수한 피해는 작은 하늘색 숫자, 내 유닛이 입은 피해는 빨간 `-숫자`, 회피는 `회피`로 위로 떠오르며 사라진다. 서버가 이벤트(`ev`)로 피해량과 때린/맞은 사람을 알려 주고, 같은 대상에게 한 틱에 들어간 피해는 합쳐서 보낸다. 다른 플레이어의 피해는 띄우지 않는다.
  - **배후 공격**: 방어하는 쪽의 등 뒤(반각 60도)에서 오는 공격은 피해(돌격 피해 포함)가 **1.5배**다. 적·아군 모두에게 적용되고, 유닛은 마지막으로 이동·공격한 방향을 바라본다. 기병이 옆·뒤로 우회하는 이유이자 가장 큰 보상이다(방패는 어차피 정면만 막는다). 아군이 등 뒤를 때리면 주황 사선이 뜬다.
- **진형 편성(B)** *(현재 화면에서 숨겨 둠: 하단 진형 선택 줄과 B 키를 껐다. 다시 켜려면 `client/src/formation.ts`의 `FORMATION_UI_ENABLED`를 `true`로 바꾼다)*: 병종마다 설 구역(전열·중열·후열·좌익·우익·양익·후위 호위)과 간격을 골라 4개까지 저장하고, 전투 중 화면 아래 버튼으로 바꾼다(단축키는 정리 중이라 비워 두었다. F1~F3은 용병 명령). 저장은 브라우저에 하고 접속할 때 서버에 다시 알린다. 로직은 `shared/src/formation.ts`.
- **기병 그림(8방위)과 플레이어 색**: 기병은 8방위 기본 자세·찌르기 자세 그림(`client/public/assets/units/cav_{idle,thrust}_{0..7}.png`, 0=북에서 시계 방향)을 쓴다. 움직인 방향(공격 중이면 공격 방향)을 따라 방향이 바뀌고, 공격하는 동안은 찌르기 자세이고, 달릴 때는 달리기 4프레임(`cav_run_{방향}_{프레임}.png`, 기본 자세의 다리 부분을 변형해 만든 그림)이 속도에 맞춰 돌아가고 살짝 출렁인다(`cavGait`). 새로 그린 달리기 그림을 받으면 같은 이름으로 바꿔 넣으면 된다. 아군 용병은 병종 상관없이 **주인 플레이어의 대표 색**(`PLAYER_COLORS`, 토너먼트에서는 팀 색)으로 망토·옷·깃털 부분만 색상을 바꿔 칠해(`client/src/recolor.ts`, 병종마다 바꿀 색 범위 규칙) 구분된다. 적 기병은 어두운 붉은색이고, 아군 색 팔레트에는 빨강·주황 계열을 넣지 않아 적과 헷갈리지 않는다. 기존 `ally_cavalry.png`/`enemy_cavalry.png`는 남겨 두었다(현재는 쓰지 않음).
- **용병**은 주인공 주변 진형 자리(앞줄 검방·둔기 / 중간 창 / 뒷줄 궁 / 기병은 양옆 날개)를 따라다니며 자동으로 싸운다. 각자 체력이 있고, 쓰러지면 부활한다(기병 40초, 나머지 30초).
- **통솔력**: 용병마다 비용(기병 2, 나머지 1)이 있고, 보유 용병의 비용 합이 통솔력(시작 5)을 넘을 수 없다. 늘리는 방법은 레벨업 선택지(예정).
- **캠프**가 무작위로 생기고, 적을 잡아 모은 금화로 용병을 고용한다(보유 수가 늘수록 비싸짐). 캠프에서는 해고도 되고 지불한 금화의 절반을 돌려받는다.
- **기병**은 자신이 강한 적(특히 궁병)을 먼저 노려 옆·뒤로 돌아 들어가고, 창병 적은 피해 돌며, 공격한 뒤엔 잠깐 물러난다(치고 빠지기). 평소 활동 범위는 넓고, **우클릭으로 돌격 지점을 지시**하면 6초간 그 지점으로 나가 싸운다(체력이 낮으면 자동 복귀).

- **경험치와 레벨업**: 적을 잡으면 경험치의 50%는 처치한 사람(용병이 잡아도 주인)에게, 나머지 50%는 접속한 모든 플레이어에게 똑같이 나뉜다(뒤처져도 따라갈 수 있게). 레벨업하면 각자 화면에 카드 3장이 뜨고, **게임은 멈추지 않는다**. 키 한 번(Z/X/C)으로 고르고, 시간 제한이 없으며 여러 번 레벨업하면 쌓여서 차례로 뜬다. 카드는 규모(통솔력·고용 할인·전리품) / 용병 강화 / 주인공 강화에서 섞여 나오고, 가진 병종의 단련 카드만 나온다. 카드 목록은 `shared/src/cards.ts`.

- **주인공 무기**: 활(원거리, 방패 정면에는 25%) / 창(긴 찌르기, 기병 돌격 무효·먼저 찌르면 카운터, 방패에 60%) / 검(빠른 휘두르기, 방패 체력이 정면 공격을 먼저 받아 냄) / 철퇴(느리고 강함, 방패에 300%, 범위 공격). 병종과 같은 규칙이 무기에 적용되므로 상황에 맞춰 바꾸면 유리하다(화면 오른쪽 아래에 현재 무기의 특징이 표시된다). 무기를 바꾼 직후 0.25초는 공격할 수 없다.
- **카드 등급**: 수치 카드는 같은 능력치라도 **일반 / 희귀 / 영웅**이 있다(효과 x1 / x1.6 / x2.4, 관통·통솔력은 +1/+2/+3). 등급이 높을수록 드물게 나오고(확률 x1 / x0.4 / x0.12) 늦게 나온다(레벨 1 / 3 / 6부터). 카드 테두리 색(회색 / 파랑 / 보라 / 전설 주황)과 별 개수로 구분한다.
- **병종 육성**: 용병 강화 카드의 주력은 **병종 전용 카드**다(기병 체력·공격력·이동 속도·치명타·회피·공격 속도·범위 / 창병 체력·공격력·사거리·방어력·공격 속도·범위 / 궁병 공격력·사거리·공격 속도·치명타·관통 / 검방병 체력·방어력·재생·공격력·부활 단축·공격 속도·범위 / 둔기병 공격력·범위·체력·치명타 피해·공격 속도). 전체 용병 카드는 같은 효과의 **20%**(`GLOBAL_CARD_FACTOR`)라 골고루 키우는 쪽은 약하지만 폭이 넓다. 한 병종을 많이 거느릴수록 그 병종 카드가 더 자주 나온다(최대 2배). 병종 간 상성(방패·돌격·반사·범위)은 그대로 확실하므로 한 병종만 키우면 상성에 막히고, 섞어서 키우면 상성을 메운다.
- **카드 새로고침(R)**: 시작 1회, 카드를 고를 때마다 1회씩 얻는다(최대 5). 지금 제시된 카드 3장을 방금 본 카드와 겹치지 않게 다시 뽑는다.
- **용병 개별 강화(U)**: 용병 한 명씩 5단계(예: 창병 → 장창병 → 중갑 장창병 → 정예 장창병 → 창술 대가)까지 금화로 올린다. 단계마다 체력·공격력이 오르고 병종별 보너스가 붙는다(기병 속도, 창·궁 사거리, 검방병 방패, 둔기병 범위). 강화 즉시 늘어난 체력만큼 회복하고, 해고하면 강화 비용도 절반 환급된다. 수치는 `shared/src/tiers.ts`.
- **물량 vs 정예**: 통솔력은 병종 기본 비용에 **단계마다 +1**(예: 창병 1 → 창술 대가 5, 기병 2 → 6)이고 강화할 때도 +1이 든다. 그래서 통솔력당 전투력은 하급병을 많이 모으는 쪽이 낫다. 대신 **군세**(살아 있는 용병 1명당 공격력 +2.5%, 최대 +40%)는 숫자가 많을 때만 유지되고, 용병이 6명 이상인 부대가 6초 안에 최소 3명이면서 부대의 30% 이상이 쓰러지면 **사기 저하(공포)**가 걸려 모든 용병이 `SHAKEN_SEC`(3초) 동안 싸우지 않고 적에게서 멀어지는 쪽으로 도망친다(풀린 뒤 10초는 다시 걸리지 않음). 광역 피해나 큰 피해에 무너지기 쉽다(작은 부대에는 걸리지 않는다. 상태는 화면 왼쪽 위에 표시). 정예는 사거리·속도·방패 같은 단계 보너스와 적은 숫자로도 버티는 개별 전투력이 장점이다. 수치는 `shared/src/tiers.ts`.
- **캠프 고용 단계**: 시간이 지날수록(240초마다 최고 단계 +1, 최대 5단계) 캠프에 높은 단계 용병이 섞여 나오고, 가격은 하나씩 강화하는 비용의 합 + 20%(2단계 x2.64 ... 4단계 x16.2)로 비싸다. 높은 단계 용병은 부활도 단계마다 15%씩 오래 걸린다(기본: 기병 40초, 나머지 30초).
- **용병 이름과 경험치**: 용병마다 "수식어 + 이름"(예: 붉은 카일)이 무작위로 붙고, 같은 주인의 용병끼리는 겹치지 않는다. 용병은 자기 경험치를 가지며, 피해를 주거나 받을 때 조금씩, **막타를 치면 많이**(14, 보스 x4) 오른다. **경험치를 다 채워야만 강화 버튼이 뜬다**(필요량 200/450/900/1600, 금화도 필요. 강화 폭은 체력 ×1.4/1.9/2.5/3.3, 공격력 ×1.3/1.7/2.2/3.0으로 단계마다 확실히 체감되게 높이는 대신 필요 경험치도 크게 높여 달성하기 어렵게 했다). 채우면 알림이 뜨고 머리 위에 노란 화살표가 생긴다. `N`을 누르면 모든 용병의 이름이 보인다.
- **근접 반사(기본 카드)**: 가시 갑옷은 전설에서 빼서 일반 카드로 바꿨다. 일반/희귀/영웅이 각각 **2 / 4 / 6**(레벨 3부터)이고 쌓인다. 근접 공격을 받을 때마다 그 수치의 **고정 피해**(주인공·용병의 공격력 %와 단계 배율을 곱하고, 준 피해만큼 흡혈도 받는다)를 공격자에게 되돌린다(방어력·방패와 무관). 방패·방어력을 키우는 검방 위주 육성이 맞을수록 조금씩 깎아 주는 용도다. 화살·마법·독에는 없다. 주인공 카드와 창병·검방병·둔기병 전용 카드가 있고 전체 용병 카드는 없다.
- **전설 능력(카드 분류 "전설")**: 드물게(가중치 0.6, 레벨 6부터) 나오고, 같은 (능력, 대상) 조합은 한 번만 고를 수 있는 시너지 카드. **적용 대상이 정해져 있다**: 주인공만, 또는 특정 병종만(양쪽에 겹쳐 적용되지 않는다). 예: 주인공 처형 / 창병 처형 / 둔기병 처형, 궁병 폭풍 연사, 기병 돌격 가속, 검방병 불사. 능력은 폭풍 연사(치명타 시 대기시간 제거), 피의 갈증, 관통 증폭, 처형, 돌격 가속, 불사, 광역 증폭, 전장의 함성(대상이 처치하면 그 대상의 공격 속도 중첩). 대상 목록과 수치는 `LEGENDS`·`LEGEND_CONST`(`shared/src/cards.ts`).
- **난이도와 레벨 주기**: 적 생성량(+22%)과 스테이지별 체력 성장(+22%)을 올려 기본 난이도를 높였고, 레벨업 필요 경험치를 12 + 9 x (레벨-1)로 낮춰 카드가 잦게 나온다.
- **경제·성장 카드(규모 분류)**: 전리품(처치 금화 +25/40/60%), **보상금**(스테이지·소대 클리어 금화 +30/48/72%), **경험치**(주인공 경험치 +15/24/36%), 병종별·전체 **용병 경험치 획득**(용병이 빨리 강화 가능해짐), **행운**(+20/32/48%): 행운 1.0마다 희귀 x4, 영웅 x7, 전설 x9 배율로 높은 등급 카드가 잘 뜬다(일반은 그대로, 상한 3.0). 행운은 화면 왼쪽 위에 표시된다.
- **넉백 카드**: 주인공용(일반 +30 / 희귀 +48 / 영웅 +72)과 기병·창병·검방병·둔기병 전용, 전체 용병용(효과 20%)이 있다. 맞은 적은 공격해 온 반대쪽으로 그만큼(px) 밀려나고, 하던 공격 동작이 끊기며 0.4초간 공격하지 못한다. 보스는 25%만 밀린다(상한 160px). 화살도 날아온 방향으로 민다.
- **공격 능력치 카드**: 공격력, 사거리, 관통(화살이 적을 더 뚫음), 치명타 확률(상한 75%, 기본 피해 x1.5), 치명타 피해, 범위(근접 부채꼴·범위 공격 반경)가 주인공용·용병용으로 각각 있다. 치명타는 공격 한 번에 한 번 판정하고 노란 별로 표시된다. 궁병 관통 카드는 궁병이 있을 때만 나온다.
- **생존 능력치 카드**: 방어력(받는 피해 감소, 아래 "효율 고정" 참고), 회피율(공격을 완전히 피함, 흰 고리로 표시), 체력 재생(주인공은 초당 고정량, 용병은 최대 체력 비율), 최대 체력이 주인공용·용병용으로 있다.
- **레벨업 순간**에는 주변(240px) 적이 밀려나고 잠깐(0.8초) 공격하지 못한다. 카드를 고를 틈을 주기 위함.

- **목표는 스테이지 10.** 스테이지마다 **3분의 자유 성장 시간**(일반 적이 계속 나오고, 캠프·레벨업으로 키운다) 뒤에 **보스군**이 먼 곳에서 진형을 갖추고 행군해 온다. 장군이 쓰러지면 클리어(금화·경험치 보상, 쓰러진 동료 자동 부활, 10초 휴식)이고 다음 스테이지로 간다. 스테이지가 오를수록 적의 체력·피해·생성량이 늘어난다. 10스테이지 장군을 잡으면 승리.
- **적 소대**: 보스가 아닐 때도 성장 단계에서 가끔(첫 소대는 스테이지 시작 30초 뒤, 이후 약 40초 간격, 스테이지가 오를수록 짧아짐) **소규모 혼성 부대**가 진형을 갖추고 다가온다. 병종끼리 서로의 약점을 가려 주도록 짜여 있다: 방패 벽(검방병이 화살을 막고 궁병이 뒤에서 쏨) / 창 방진(창병이 돌격을 막고 검방병·궁병이 받침) / 기마 돌격(기병이 우회하는 동안 궁병·검방병이 정면을 잡음) / 파쇄조(둔기병이 방패를 부수고 창병이 옆을 지킴) / 혼성 돌파. 규모는 4 + 스테이지 + 인원 x 0.8(최대 14). 병사는 보스군처럼 진형 자리를 지키며 행군하다가 가까워진 아군만 쫓는다. 전멸시키면 병사 1명당 4G를 모두가 받고, 화면 위에 소대 수가 표시된다. 구성은 `server/src/stage.ts`의 `SQUAD_KINDS`.
- **보스군**: 병력은 (10 + 6 x (스테이지-1)) x 접속 인원^0.8(최대 260). 앞줄 검방병 → 창병 → 둔기병 → 장군 → 궁병 순으로 줄을 서고, 기병은 양옆 날개에 선다. 장군은 스테이지마다 병종이 다르고(검방·창·기병·둔기·궁) 크고 튼튼하다. 병사는 진형 자리를 지키며 천천히 전진하다가, 가까이 온 아군만 쫓고(너무 멀어지면 자리로 복귀) 싸운다. 수치는 `shared/src/rules.ts`의 STAGE_*/ARMY_*/BOSS_*, 진형 계산은 `server/src/stage.ts`.
- **쓰러짐과 부활**: 주인공의 체력이 0이 되면 쓰러져 움직이지 못하고(용병은 계속 싸운다), 동료가 곁(70px)에서 **E를 5초간 누르고 있으면** 체력 절반으로 일어나 2초간 무적이다. 중간에 멈추거나 떨어져도 진행도가 한 번에 사라지지 않고 채울 때의 4분의 1 속도로 조금씩 줄어들어, 다시 시작하면 이어서 채운다. **모든 주인공이 쓰러지면 게임오버.** 혼자 하면 쓰러지는 즉시 끝이다.
- **명중 알림**: 화살 명중·방패 막힘/깨짐·부활은 서버가 이벤트(`ev`)로 알려 주고, 클라이언트는 그대로 그린다(추정하지 않음).
- 시험 플레이용으로 서버를 `MERC_STAGE_GROW_SEC=20`처럼 띄우면 성장 시간이 줄어 보스군을 빨리 볼 수 있다.

## 소리

소리 재생 코드는 들어 있고, **파일이 없으면 조용히 건너뛴다**(지금은 파일이 없다). `client/public/assets/audio/`에 `<이름>_<번호>.ogg`(또는 `.wav`, `.mp3`)로 넣으면 바로 나온다. 이름·제작 문구는 `docs/asset-prompts.md` 10장, 음량·간격·동시 개수는 `shared/src/audio.ts`.

- **연결된 소리**: 화살 발사·명중, 근접 타격, 방패 막힘·깨짐, 치명타, 배후 공격, 넉백, 회피, 적 처치, 무기 휘두르기, 피격, 레벨업, 카드 선택·새로고침·전설, 금화, 고용, 강화 가능·완료, 쓰러짐·부활(진행 중 반복음 포함), 사기 저하, 소대·보스 경고, 스테이지 클리어·승리·패배, 캠프 진입, 버튼 클릭, 기병 돌격·질주, 배경 음악(로비 / 성장 / 보스).
- **자연스럽게 들리도록**: 같은 소리는 최소 간격과 동시 개수를 제한하고(전체 28개), 변형이 여러 개면 번갈아 틀며 음높이를 조금씩 흔든다. 위치가 있는 소리는 내 주인공과 멀수록 작아지고 좌우로 치우친다(950px 밖은 들리지 않음). 알림 소리(레벨업 등)는 제한 없이 항상 난다.
- **설정**: 오른쪽 위 스피커 버튼 또는 `M`으로 음소거, `Esc` 방 메뉴에서 효과음·음악 음량. 설정은 브라우저에 저장된다. 브라우저 정책상 **첫 클릭이나 키 입력 뒤부터** 소리가 난다.
- 서버가 알려 주는 이벤트(`ev`)에 맞춰 소리를 내므로, 화면에서 보이는 것과 소리가 어긋나지 않는다.

## 방 관리

- **로비**: 방 목록(실시간 갱신, 대기 중/진행 중 표시), 빠른 시작(공개 방 중 사람이 많은 곳, 없으면 새로 만들어 바로 시작), 방 만들기(공개/비공개), 4글자 코드로 참가.
- **비공개 방**: 목록과 빠른 시작에 나오지 않고 코드를 아는 사람만 들어온다. 같은 주소에서 코드를 8번 연속 틀리면 60초 동안 참가 시도를 막는다(무작위 대입 방지). 프록시/터널 뒤에서는 `TRUST_PROXY=1`이 필요하다(`docs/deploy.md`).
- **대기실**: 방을 만들면 대기실에서 시작한다. 참가자는 "준비"를 누르고 방장은 접속 중인 모두가 준비하면 "게임 시작"을 누른다(혼자서도 시작 가능). 시작 전에는 게임이 진행되지 않고 조작도 받지 않는다. 시작한 뒤에는 새로 들어와도 준비 없이 바로 합류한다. 연결이 끊긴 사람은 시작을 막지 않는다.
- **게임이 끝나면**(승리/전멸) 결과 화면(스테이지·시간·플레이어별 레벨/처치/부활시킴)이 뜨고, 방장이 "다시 하기"를 누르면 같은 참가자로 대기실에 돌아간다. 끝난 방에는 새로 들어올 수 없다.
- 방마다 **독립된 판**이고 최대 8명, 서버 전체 방은 30개까지. 아무도 없는 방은 사라진다.
- **방장**은 처음 만든 사람이고, 다른 참가자를 내보낼 수 있다. 방장이 나가면 다음 사람에게 넘어간다. `Esc`로 방 메뉴(코드·참가자·내보내기·나가기)를 연다.
- **접속이 끊겨도 30초**는 자리를 지킨다. 그 안에 같은 브라우저 탭에서 다시 접속하면(새로고침 포함) 같은 캐릭터·용병·금화로 이어서 한다. 기다리는 동안 주인공은 제자리에 서고 적의 목표가 되지 않으며, 용병은 계속 싸운다. 30초가 지나면 방에서 빠진다.
- 서버는 메시지 크기(2KB)와 빈도(초당 120회)를 제한하고, 응답 없는 연결은 주기적으로 확인해 정리한다. 방 로직은 `server/src/rooms.ts`.

## 최근 조정 (플레이 피드백 반영)

- **창**: 주인공 창과 창병 용병은 사거리가 훨씬 길고(112 / 100), 공격 범위가 부채꼴이 아니라 **앞으로 뻗은 직사각형**이다. 몸 앞에서 끝까지 폭이 같다(반폭 15px, `SPEAR_HALF_WIDTH_NEAR/FAR`를 다르게 두면 사다리꼴). 범위 증가 능력은 폭에 적용된다. 검·방패와 확실히 구분되는 "찌르기". 로직은 `shared/src/rules.ts`의 `inSpearBox`.
- **철퇴(주인공)·둔기병**: 한 방이 훨씬 세지만(주인공 30, 용병 32.4) 휘두르기 전 준비가 길다(주인공은 **꾹 눌러 1초 모으고 떼면 휘두름**, 용병 0.9초). 주인공은 모으는 중 철퇴 범위가 점점 진하게 차오른다.
- **체력 재생·흡혈 대폭 너프**: 재생 카드 주인공 초당 0.2(일반), 용병 초당 최대 체력의 0.4%. 피의 갈증은 준 피해의 4%.
- **적이 계속 강해진다**: 스테이지 성장(체력 +30%, 피해 +14%, 물량 +18%)에 더해, 같은 스테이지 안에서도 60초마다 체력 +12%·피해 +5%, 접속자 평균 레벨이 1 오를 때마다 체력 +3.5%·피해 +1.5%(성장을 따라잡는다).
- **통솔력 카드**가 가장 흔한 카드이고, 통솔력이 거의 찼으면 2.5배 더 자주 나온다.
- **용병 경험치 요구량** 3.5배(당시 140/280/500/800, 이후 200/450/900/1600으로 상향). 용병 기본 능력치는 체력·공격력이 약 +45~50%(둔기병은 +40%), 주인공 기본 무기는 약 -30%.
- **궁병 용병 카이팅**: 근접 적이 (적 사거리 + 55px) 안으로 오면 진형 쪽으로 물러나며 쏜다. 용병의 추격 범위(leash)는 줄여 적진 한가운데로 뛰어들지 않는다.
- **기병** 최고 속도 230 → 300(적 기병은 190 → 230).
- **기록**: 게임이 끝나거나(승리·전멸) 중간에 나가면 준 피해·받은 피해·쓰러짐·금화·용병 수 등이 담긴 기록이 뜨고, 브라우저에 최근 20판까지 저장된다(로비의 "최근 기록 보기", 방 메뉴의 "지금까지 기록"). 중간에 "방 나가기"를 누르면 먼저 기록을 보여 주고 확인을 받는다.
- **라운드와 보스**: 한 라운드(자유 성장 시간)는 2분. 보스군이 나타난 지 1분 안에 못 잡으면 **격노**가 시작된다: 20초마다 격노 단계가 오르며 부하가 약 10%(최소 3명) 더 늘고, 기존 부하와 새 부하의 체력·방어막·피해가 +8%씩, 이동 속도가 +2%씩 강해진다(최대 12단계, 화면에 "격노 Lv.N" 표시). 그래도 4분(`BOSS_HARD_TIMEOUT_SEC`, 0이면 무제한)이 지나면 보스군이 물러나고 다음 스테이지로 넘어간다(보상 없음, 마지막 10스테이지는 끝까지 잡아야 한다).
- **용병 중심 밸런스**: 주인공 체력 100→80, 주인공 무기 피해 -20%, 용병 체력·공격력 +25%(마법사 피해는 그대로). 체력 재생은 절반(주인공 초당 0.06 기본, 용병 0.125%), 흡혈은 1/4(카드 0.3/0.5/0.7%, 피의 갈증 0.6%).
- **난이도(개인별)**: 대기실에서 **각자** 자기 난이도를 고른다(쉬움 75% / 보통 50% / 어려움 25% / 매우 어려움 0%, 기본은 매우 어려움). 숫자는 그 사람의 주인공·용병이 적에게 받는 피해의 감소율이고, 다른 사람에게는 영향이 없다(토너먼트 대결에는 적용하지 않는다). 대기실 참가자 목록에 모두의 난이도가 보이고, 게임이 시작되면 바꿀 수 없다. **랭크(ELO 등) 방**은 `Room.ranked`를 켜면 난이도가 `RANKED_DIFFICULTY`(피해 감소 없음)로 고정되고 바꾸려는 요청은 거절된다(랭크 방을 만드는 길은 아직 없다).
- **관전**: 쓰러져 있을 때 스페이스를 누르면 살아 있는 동료를 따라가며 구경한다(스페이스를 다시 누를 때마다 다음 동료, 마지막 동료 다음에는 관전이 끝난다. Tab 또는 ←/→로 앞뒤 이동, 일어나면 자동으로 끝).
- **용병 흩어짐**: 아군 용병끼리 반지름 합 x 1.9 이내로 붙으면 서로 밀어내고(`MERC_SPACING`, `MERC_SEPARATION_SPEED`), 마주 보고 지나가는 둘은 옆으로 비껴 간다. 주문·공격 준비 중인 용병은 제자리를 지킨다.
- **주인공 검 방패**: 검을 들면 방패 체력 240(`HERO_SHIELD_MAX`)이 정면 공격을 먼저 받아 낸다. 몸이든 방패든 맞고 나면 5초(깨졌으면 6초) 동안 맞지 않아야 초당 최대치의 5%씩 차오른다. 정면 피해 50% 감소는 없앴다(방패가 없으면 그대로 맞는다). 체력 막대 아래 파란 막대와 "방패 N"으로 보인다. 카드: **방패 체력**(+80/+128/+192, 희귀도별), **방패 재생 속도**(+40%/+64%/+96%) — 검을 들었을 때만 효과가 있다.
- **철퇴·검 범위**: 범위 증가(카드·강화)가 철퇴(주인공)·둔기병·검(주인공)·검방병에서는 몸 둘레로 부채꼴을 넓히지 않고 **앞쪽으로 길게** 늘린다(각도는 그대로, 사거리와 폭발 반경이 범위 배율만큼 커진다). 기마는 이전처럼 각도가 넓어진다.
- **시전 시간 카드**: 마법사 용병 전용 "시전 시간 -10%/-16%/-24%"(곱셈으로 쌓이고 원래의 30% 밑으로는 줄지 않는다), 주인공 지팡이용 "시전 시간" 카드도 있다.
- **지형(판마다 새로 생성)**: 방이 게임을 시작할 때마다 바위·나무·폐허·고지대가 새로 깔린다(`shared/src/terrain.ts`, 시작 지점 둘레는 평지). 바위·나무 밑동·폐허는 **통과할 수 없고**(주인공·용병·적 모두 밀려난다), 바위·폐허는 **화살도 막는다**(나무는 화살이 지나간다). 폐허·바위 방벽 사이에는 좁은 통로가 있다.
  - **고지대**(크게 그려진다): 윗면에서는 이동 속도 ×0.85, 올라가는 비탈은 ×0.4(`PLATEAU_TOP_SPEED`, `SLOPE_SPEED`). **고지대에서 낮은 곳으로 쏜 화살은 피해 +40%**, 낮은 곳에서 고지대로 쏘면 -20%(`HIGH_GROUND_ARROW_MULT`, `LOW_GROUND_ARROW_MULT`). 주인공은 HUD에 "고지대/비탈" 안내가 뜨고, 미니맵에 고지대(갈색)·바위(회색)가 보인다.
  - 고지대는 제공받은 새 에셋(시트 2장)으로 바꿨다. **올라가는 길(계단·다리)이 있는 고지대는 그 길로만 오르내릴 수 있고**, 나머지 절벽은 통과할 수 없다(화살은 절벽을 넘어간다). 길 위는 `RAMP_SPEED` ×0.75, 윗면은 ×0.85. 용병과 적도 길을 찾아 오르내린다(`TerrainMap.route`). **길이 없는 산**은 통째로 통과할 수 없는 장애물(화살도 막는다)이다. 고지대 크기는 650~950px(작은 것 520~760px). 길이 넓은 고해상도 고지대 2종(`t70`, `t71`, 길 폭 약 120px)도 있다.
  - 지형 그림은 접속할 때 전부 미리 불러온 뒤 시작한다. 해상도가 낮은 옛 에셋(번호 40 미만)은 45% 크기로, 새 시트의 작은 바위는 70%로 줄여 쓰고, 고지대도 원본의 1.0~1.25배(고해상도 800px급은 0.85~1.05배)까지만 확대하며(흐려 보이지 않게), 화면 배율이 높은 기기에서는 최대 2배 해상도로 그린다. 나무는 밑동 충돌 범위를 키웠고(통과하기 어렵게) 개수도 줄였으며(나무·장식·폐허), 바위는 새 에셋이 옛 것보다 4배쯤 자주 나온다.
  - 토너먼트 중에는 경기장에 걸친 지형이 사라진다. 캠프는 바위·고지대 위에 세워지지 않는다.
  - 그림은 제공받은 에셋 시트에서 잘라 `client/public/assets/terrain/`에 두었고(충돌 모양은 `shared/src/terrain-data.ts`), 고지대는 약 3배로 확대해 쓴다.
- **토너먼트 팀 색**: 싸울 때는 나=파랑, 상대=빨강. 관전할 때는 대진 앞쪽 선수=빨강, 뒤쪽 선수=파랑. 링·이름표·체력 막대·미니맵 점이 모두 팀 색으로 칠해진다.
- **보스 상자**: 보스를 쓰러뜨리면 접속 인원 수만큼 상자가 떨어진다. 상자마다 주인이 있고, 주인이 다가가면 열려 **레벨업과 별개로** 카드 한 장을 고른다(행운이 +150% 더해진 것처럼 높은 등급이 잘 나온다). 5분 안에 못 열면 사라진다.
- **토너먼트**(3·6·9·10 스테이지, 2명 이상일 때): 보스를 잡으면 남은 적과 캠프를 모두 없애고 접속한 플레이어끼리 1대1 토너먼트를 연다. 대진은 무작위, 인원이 2의 거듭제곱이 아니면 부전승이 생긴다. 각자 자기 용병을 데리고 경기장(중앙, 반지름 800 — 기병이 달릴 수 있게 넓다)에서 싸우고, **주인공이 쓰러지면 패배**(동시면 남은 전력이 큰 쪽)다. 60초가 지나면 주인공+용병의 남은 체력 비율이 높은 쪽이 이긴다. 선수가 아닌 사람은 가장자리에서 관전하며 공격할 수 없다. 보상: 경기 승리 금화(30 x 스테이지), 준우승 금화(50 x 스테이지), 우승 금화(100 x 스테이지)와 경험치(60 x 스테이지). 끝나면 모두 체력·용병이 회복되고, 10스테이지 토너먼트가 끝나면 게임 승리. 수치는 `shared/src/rules.ts`의 `TOURNAMENT_*`.
- **주인공 능력치 상자**(왼쪽 아래): 지금 든 무기와 카드가 반영된 공격력·초당 공격 횟수·사거리·치명타(확률 ×배율)·관통·범위·방어력·회피·재생·이동 속도·넉백·행운의 실제 값을 보여 준다(무기를 바꾸면 같이 바뀐다).
- **미니맵**(왼쪽 위 상태 상자 아래, 상자와 같은 폭, **G** 키로 켜고 끈다. 화면이 낮으면 정사각형이 작아진다): 월드 전체를 작게 보여 준다. 아군 주인공·용병은 주인 색 점, 내 주인공은 방향 화살표, 적은 붉은 점(보스는 큰 주황 점), 캠프는 노란 네모, 내 보상 상자는 금색 상자로 보이고, 카메라가 보는 범위가 흰 네모로 표시된다. **쓰러진 주인공은 큰 X와 이름, 부활 진행률(초록 호)**, 쓰러진 용병은 작은 X로 그 자리에 남고, 방금 쓰러진 곳은 5초 동안 붉은 고리가 퍼진다. 토너먼트 중에는 경기장 원이 표시된다.
- 화면: 왼쪽 위 상태 상자(레벨·경험치·체력 막대·금화·통솔력), 캠프 고용 창과 레벨업 카드를 크게.

## 용병 AI와 진형

- **진형 모드**(화면 왼쪽 아래 버튼 또는 **V** 키): **기본 진형**은 주인공 곁 진형 자리를 지키며 그 둘레의 적과 싸운다. **돌격 진형**은 대열의 중심이 주인공보다 200px 앞으로 나가고 진형 자리를 벗어나 쫓는 거리가 약 2.4배(기병 1.6배)로 늘어난다. 진형 편성(B)과는 별개로 켜고 끌 수 있다.
- **병종별 역할**(기본값. `shared/src/rules.ts`와 수치 조정 도구에서 바꿀 수 있다):
  - **검방병**: 다른 병종 중 가장 취약한 아군(궁병 > 주인공 > 창병 > 둔기병 > 기병)을 지킨다. 아군 옆이 아니라 아군과 위협을 잇는 선의 중간에 서서 방패 정면을 위협 쪽으로 향한다.
  - **궁병**: 사거리의 약 88% 거리(최대 사거리 근처)에서 쏜다. 방패가 정면을 막은 적은 뒤로 미루고, 그 적을 쏴야 하면 옆으로 돌아 정면을 피한다. 근접 적이 다가오면 진형 쪽으로 물러나며 쏜다.
  - **기병**: 옆·뒤로 돌아 들어가 배후 공격을 노리고 궁병(2.2) · 둔기병(1.8)을 먼저, 정면의 방패(0.5)는 나중에, 창병은 피한다.
  - **둔기병**: 방패 든 검방병 적을 먼저(가중 2.6배) 노린다.
  - **창병**: 지킬 아군(궁병·주인공)이 있으면 그 아군과 위협(적 기병을 먼저) 사이의 중간에 서서 창끝을 위협 쪽으로 겨누고(돌격 진형에서는 앞으로 나가 싸운다), 지킬 아군이 없으면 적 기병을 주시하며 가까운 적과 싸운다.
- **적 AI**(일반 적·소대·보스군 모두, 진형을 벗어나 싸울 때): 뭉쳐서 곧장 쫓아오지 않고 **대상을 둘러싼다**. 개체마다 정해진 쪽으로 최대 약 110도 비껴 크게 돌아 접근하고, 가까워질수록 곧장 붙기 때문에 한쪽으로 달아나면 반대쪽이 앞을 막는다. 움직이는 대상은 **이동 방향을 예측해 앞질러** 가고, 적 이동 속도에는 배율(`ENEMY_SPEED_MULT` 1.15)이 붙는다. 그래서 주인공·용병의 이동 속도(카드 +12%로 상향)가 포위를 뚫는 데 중요해진다.
  - **검방병**: 가까운 적 궁병이 있으면, 궁병 옆이 아니라 **궁병과 위협(내 주인공·용병)을 잇는 선의 중간**에 서서 방패를 위협 쪽으로 향하고, 위협이 다가올수록 그 지점도 앞으로 좁혀 온다(`GUARD_MID_FRAC` 0.5). 궁병이 없으면 앞장서 밀고 들어간다.
  - **궁병**: 사거리 끝 근처에서 대상 둘레를 돌며 에워싸 쏘고, 내 근접 용병이 다가오면 물러나며 쏜다. 방패가 정면을 막은 용병은 피해서 다른 쪽을 먼저 쏘고, 쏴야 하면 옆으로 돈다.
  - **기병**: 내 궁병(2.2)·둔기병(1.8)을 먼저 노리고 정면의 방패(0.5)는 나중에, 대상의 옆·뒤로 돌아 배후 공격(x1.5)을 노린다. 내 창병은 피해 돌고(달려들다 창에 맞으면 속도를 잃고 카운터를 입으므로), 공격한 뒤에는 빠졌다가 다시 달려든다.
  - **둔기병**: 방패 든 내 검방병을 먼저(2.6배) 노린다.
  - **창병**: 검방병과 같이 궁병과 위협(내 기병을 먼저) 사이의 중간에서 창끝을 위협 쪽으로 겨누며 좁혀 온다. 궁병이 없으면 가까운 적과 싸운다.
- 토너먼트에서도 같은 AI가 상대 선수의 주인공·용병을 대상으로 움직인다. 창의 카운터도 경기에서 적용된다(달려오는 기병 용병이 창을 든 상대에게 먼저 맞으면 속도를 잃고 카운터를 입는다).

## 수치 조정 도구

서버를 켠 컴퓨터의 브라우저에서 **http://localhost:8080/tuning.html** 을 열면(개발 중에는 5173 포트) 용병·적·무기 능력치, 가격, 성장 속도, 보스·토너먼트·AI 수치 등 약 400개를 화면에서 바꿀 수 있다. 검색창으로 찾고, 바꾼 칸은 노랗게 표시되며, 항목마다 "기본값" 버튼이 있다. **저장하고 적용**을 누르면 게임 중인 사람들에게도 바로 적용되고 서버 폴더의 `tuning.json`에 저장되어 서버를 다시 켜도 유지된다(`tuning.json`은 저장소에 올라가지 않는다). 보안: 서버를 켠 컴퓨터(프록시·터널을 거치지 않은 요청)에서만 열리고, 터널로 밖에서 쓰려면 서버를 `MERC_ADMIN_TOKEN=비밀값`으로 켠 뒤 `?token=비밀값`을 붙여 연다. 저장 파일 위치는 `MERC_TUNING_FILE`로 바꿀 수 있다. 새 숫자를 이 도구에 올리려면 `shared/src/tuning.ts`에 항목을 추가한다.

## 자동 업데이트로 서버 켜기

서버를 켜 둔 컴퓨터에서 `서버시작.bat`을 더블클릭하거나 `npm run serve`를 실행하면, 시작할 때 최신 버전을 받아 빌드한 뒤 서버를 켜고 **1분마다 GitHub에 새 버전이 올라왔는지 확인**한다. 새 버전이 있으면 접속자가 한 명도 없을 때 스스로 `git pull` → (패키지가 바뀌었으면 `npm install`) → `npm run build` → 서버 재시작을 한다. 접속자가 있으면 기다리고(`--force-after 30`을 주면 30분 기다린 뒤에는 접속자가 있어도 한다), 서버가 죽으면 5초 뒤 다시 켠다. 확인 간격은 `--interval 초`, 브랜치는 `--branch 이름`으로 바꾼다. 이 컴퓨터에서 직접 고친 파일이 있어 `git pull`이 안 되면 업데이트를 건너뛰고 지금 버전으로 계속한다(`tuning.json`은 저장소에 올라가지 않으므로 영향이 없다). Cloudflare 터널(`cloudflared`)은 따로 켜 두면 된다. 터널을 켜는 창과 이 창은 서로 독립이다.

## 배포

`npm run build && npm start` 하나로 서버가 화면과 접속(`/ws`)을 같은 포트에서 제공한다. 메시지는 압축되어 약 1/3로 전송된다. 호스팅 선택(개인 서버 + Cloudflare Tunnel 추천 / 포트포워딩 / VPS), 필요한 대역폭 실측, Docker·systemd 예시는 [`docs/deploy.md`](docs/deploy.md).

## 밸런스 점검

`npm run balance -w server -- <초> <인원 목록> <시드 수>` (예: `-- 2100 1,3,6 3`, 10스테이지는 약 2000초). 봇이 끝까지(승리·전멸·시간 초과) 플레이하는 판을 서버 로직 그대로 돌려 도달 스테이지, 주인공·용병 쓰러짐, 부활, 레벨을 뽑는다. 봇은 사람보다 훨씬 서툴러서 절대 기준이 아니라 변경 전후 비교용이다. `RESPAWN_SCALE=0.67`처럼 주면 용병 부활 시간을 그 배율로 바꿔 비교할 수 있고(출력에 "용병 쓰러져 있는 시간%"가 나온다), `DETAIL=1`을 붙이면 병종별 쓰러짐도 나온다. 수치를 바꾼 뒤 이걸로 확인한다.

## 에셋

스프라이트는 `client/public/assets/`에 있다: 병종 유닛(`units/`), 주인공 무기별 포즈(`hero/`), 캠프(`camp/`), 바닥 타일(`tiles/`), 화살(`fx/`). 이미지 도구: 시트를 한 장씩 자르는 `tools/slice_sheet.py`, 흰 배경(가짜 투명 포함)을 투명으로 바꾸는 `tools/remove_bg.py`, 바닥 타일 이음새 검사 `tools/tile_preview.py`(사용법은 각 파일 머리말과 `docs/asset-prompts.md`). 남은 에셋(카드 아이콘, 무기·HUD 아이콘, 효과음)의 제작 프롬프트는 `docs/asset-prompts.md`.

레벨업 카드는 시안(`client/public/assets/cards/art_*.png`, 병종 5종 일러스트)을 반영했다. 병종 단련·용병 체력/공격/속도·주인공 사격 카드는 이 그림을 쓰고, 나머지 카드(통솔력·가격·전리품 등)는 글자 아이콘이라 전용 일러스트가 더 필요하다. 별은 등장 확률이 낮을수록 많다.

이미지·소리 생성 AI나 아티스트에게 의뢰할 때 쓰는 프롬프트: [`docs/asset-prompts.md`](docs/asset-prompts.md)

## 현재 상태

프로토타입 11단계: 적 병종과 공격 모션, 용병 고용·진형·병종 규칙(방패·돌격·반사·범위), 캠프, 통솔력·해고, 기병 운용과 우클릭 돌격, 경험치 공유와 레벨업 카드, 주인공 무기 변경, 임시 밸런스, 병종 스프라이트, 방 관리(로비·방장·재접속·비공개 방·대기실), 주인공·캠프·바닥·화살 에셋, 스테이지 10 + 보스군 + 부활·게임오버·결과 화면, 서버 명중 이벤트.
수치(체력·피해·가격·스폰량·경험치)는 임시값이다. 봇 시뮬레이션으로 1차 조정만 했고 실제 플레이로 다듬어야 한다.

다음: 실제 플레이로 밸런스 조정, 남은 에셋(카드·무기·HUD 아이콘) 교체, 효과음, 서버 배포.

### 카드: 궁병 체력 / 발사 수
- 궁병도 `체력` 병종 카드가 나온다.
- `발사 수` 카드(주인공 활 · 궁병): 한 번에 쏘는 화살이 +1/2/3발 늘어난다(레벨 3부터). 늘어난 화살은 부채꼴로 퍼지고 피해가 `MULTISHOT_DAMAGE`(기본 70%)다. 수치 조정 도구에서 피해 비율과 각도를 바꿀 수 있다.

### 카드: 독 화살 / 피해 감소
- `독 화살`(주인공 활 · 궁병, 레벨 3부터): 화살이 몸에 맞으면 그 화살 피해의 일정 비율(일반 50% / 희귀 80% / 영웅 120%)을 4초에 걸쳐 추가로 입힌다. 방패에 막힌 화살은 독이 묻지 않는다. 다시 맞으면 시간이 새로 시작하고 더 센 쪽을 따른다. 독 피해도 킬·경험치로 인정된다. 토너먼트에서는 상대 선수의 주인공·용병에게도 걸리고, 0.5초마다 한 번씩 지속 피해로 들어가므로 피해 감소 카드가 매번 적용된다(방패·회피는 무시).
- `피해 감소`(주인공 + 모든 병종, 레벨 4부터, 희귀·영웅만): 맞을 때마다 받는 피해에서 고정치(희귀 -2 / 영웅 -4)를 뺀다. 고정치를 **먼저** 빼고 그다음에 방어력(%)을 적용한다(독 같은 잔 피해에 맞서는 용도). 한 번의 피해는 `ARMOR_MAX_FRAC`(기본 70%)까지만 줄어든다. 방패가 막는 피해에는 적용되지 않는다.

### 둔기병 경직
- 둔기병에게 맞은 적(범위 피해로 맞은 적 포함)은 `BLUNT_STAGGER_SEC`(기본 0.3초) 동안 움직이지도 공격하지도 못한다. 강화 단계마다 `BLUNT_STAGGER_PER_TIER`(0.1초)씩 늘어나 최고 단계(4)에서는 0.7초다. 보스는 30%만 걸린다. 주인공의 철퇴에는 적용되지 않는다.

- 용병 강화 패널(U)의 각 용병에는 **강화 시 늘어나는 능력치**가 초록 글씨로 표시되고(체력·공격력·병종 보너스·둔기병 경직 시간), 강화 버튼에 마우스를 올려도 보인다. 문구는 `shared/src/tiers.ts`의 `nextTierBonus`.

### 둔기병 / 검방병 밸런스
- 둔기병 체력 180(200에서 하향), 검방병(용병) 체력 160(170에서 하향)·방패 120(110에서 상향)·공격력 8(12에서 하향). 방패에 대한 둔기 피해 배율(250%)은 그대로다. 같은 단계 1대1 단순 모델에서 둔기병이 검방병을 0·2·4단계 모두 이긴다(남은 체력 약 29% / 30% / 18%). 검방병은 여전히 기병·창병·궁병에게 강하다.

### 기병 AI: 치고 빠지기
- 용병 기병은 한 대 치면 대상에서 `CAV_RUNUP_DIST`(240px)만큼 떨어져 **대상의 옆·뒤로 돌아가며 속도를 다시 붙이고**(최대 `CAV_RUNUP_SEC` 2.6초), 속도가 `CAV_RUNUP_READY`(85%) 이상이 되고 옆·뒤를 잡으면 다시 돌격한다. 그래서 돌격 한 방이 대략 두 배 세다(예: 26 → 50).
- 대상 체력이 `CAV_FINISH_HP`(30%) 이하이거나 **대상이 궁병(원거리)이면** 더 빠지지 않고 정면으로 붙어 계속 싸운다(궁병은 빠지면 물러나며 쏘기만 하므로).
- 진형에서 너무 멀리 벗어나지 않고, 체력이 낮아져 복귀할 때는 달리기를 멈춘다. 수치는 수치 조정 도구의 AI 묶음에 있다.

### 마법사 (용병 + 주인공 지팡이)
- **용병 마법사**: 체력 70·이동 속도 60으로 가장 약하고 느리지만, **2초 동안 주문을 외운 뒤** 운석을 떨어뜨린다. 한 방 150 피해에 반경 140px의 **굉장히 넓은 범위**, 사거리는 궁병 정도(280). 방패를 무시하고 몸에 들어가며, 중심은 100%·가장자리는 60%(`MAGE_FALLOFF`) 피해다. 통솔력 2, 고용 90G, 부활 40초. 진형에서는 가장 뒤에서 호위한다.
- 주문을 외우는 동안은 **움직이지 못하고**(용병·주인공 모두), 낙하 지점은 사거리 안에서 적이 가장 빽빽한 곳으로 천천히 따라가다가 낙하 `MAGE_LOCK_SEC`(0.8초) 전에 고정된다. 주문 도중 쓰러지면 운석은 떨어지지 않는다. **궁병처럼 행동한다**: 근접한 적이 다가오면 주문을 시작하지 않고 물러나며, 위협이 없으면 사거리 안에서 적이 가장 많이 모인 곳을 노린다. 적이 사거리 밖이면 진형에서 조금 앞으로 나가 사거리 끝 근처에 선다. 아군 기병은 마법사를 궁병보다 먼저 노린다(`CAV_TARGET_WEIGHT` 3.2 > 2.2).
- **주인공 지팡이**(무기 5번째, Q·휠로 전환): 같은 2초 주문이고, 운석은 **마우스가 가리키는 거리**(사거리 300까지)에 떨어진다. 주문을 외우는 동안은 **움직일 수 없지만** 마우스를 따라 낙하 지점이 움직이다 마지막 0.8초에 고정된다. 입력에 `dist`(마우스까지 거리)가 추가되었다.
- 화면: 낙하 지점에 붉은 원을 띄우고 안쪽 **음영이 시계처럼(위에서 시계 방향) 차올라** 한 바퀴를 다 돌면 떨어진다는 것을 알 수 있게 하고(모든 플레이어에게 보인다), 마지막 0.8초에 하늘에서 운석이 떨어져 폭발·그을음이 남는다. 토너먼트에서는 상대 선수의 주인공·용병이 맞는다(피할 수 있게 예고가 보인다).
- 카드: 마법사 전용 공격력·범위·사거리·공격 속도·체력·치명타·치명타 피해·경험치, 광역 증폭·전장의 함성 전설. 강화 단계마다 사거리 +5%, 폭발 범위 +10%. 수치는 `shared/src/rules.ts`(`MERC_STATS`)와 수치 조정 도구.
- **적 마법사**: 2스테이지부터(`ENEMY_MAGE_FROM_STAGE`) 드물게(생성 비율 3, 동시 수 제한은 없다) 나온다. 체력 22·이동 55로 약하고, 사거리 280에서 3.5초 주문을 외운 뒤 **아군이 가장 많이 모인 곳**(주인공은 3배 가중)에 운석(피해 55, 반경 110)을 떨어뜨린다. 낙하 지점은 **고정**이라(적은 마우스를 따라가지 않는다) 붉고 진한 원과 시계 음영을 보고 벗어나면 피할 수 있다. 외우는 동안 넉백이나 둔기병의 타격으로 밀려나면 주문이 끊긴다. 평소에는 궁병처럼 거리를 유지한다. 마법사 처치는 경험치 5·금화 8이다.

### 용병 명령(기본·돌격·지점 방어)과 기마 주인공
- **용병 명령**(왼쪽 아래 막대): **F1 주인공 호위**(기본) = 진형이 주인공 주변을 지키며 싸운다 / **F2 위치 고수**(지점 방어) = 지금 주인공이 선 곳에 깃발을 꽂고 진형을 펴서 지킨다(다시 누르면 그 자리로 옮긴다) / **F3 돌격** = 대열이 앞으로 나가 더 멀리 쫓는다. V 키는 호위 → 위치 고수 → 돌격 순으로 돌린다. 지점 방어에서는 주인공이 떠나도 용병은 그 자리에 남아 지점 근처의 적과 싸우고, 주인공 호위(F1)로 돌리면 다시 주인공을 따라온다. 우클릭 기병 돌격 지시와 진형 편성(병종별 구역, B 화면)은 그대로 쓴다.
- 지점 지정: `지점 방어` 버튼을 누르고 **원하는 곳을 클릭**(Esc로 취소)하거나 **T 키로 마우스가 가리키는 곳**을 바로 지정한다. 지점에는 내 색 깃발과 구역(반경 130)이 표시되고 미니맵에도 깃발이 뜬다. 지점을 정한 적이 없으면 주인공 앞쪽을 지킨다. 토너먼트에서는 쓰지 않는다. 서버 메시지는 `{t:"hold", x, y}`, 상태는 `PlayerState.holdX/holdY`.
- **기마 주인공**(무기 6번째 `기마`, Q·휠로 전환): 말을 탄 주인공은 달릴수록 빨라져(걷기 220 → 최고 `MOUNT_SPEED_MAX` 1.7배 = 약 374) 멈추면 다시 느려진다. 공격(사거리 54, 부채꼴 80도, 14 피해)에는 **지금 속도에 비례한 돌격 피해**(속도 1당 `CAV_DAMAGE_PER_SPEED`)가 붙고, 공격하면 속도를 30%로 잃는다. 달려가다 적 창병에게 먼저 맞으면 용병 기병처럼 **속도를 잃고 돌격 피해만큼 카운터를 입는다**(방패는 돌격을 일부 흡수). 그림은 보관해 두었던 `hero_cavalry.png`를 쓴다.

### 사기 저하(공포)
- 큰 부대(6명 이상)가 6초 안에 3명 이상, 부대의 30% 이상 쓰러지면 걸린다. 걸리면 **모든 용병이 3초 동안 싸우지 않고, 가까운 적들에게서 멀어지는 방향으로 도망친다**(이동 속도 ×1.3, 마법사 주문·공격 준비도 끊긴다). 공격력은 줄지 않는다. 풀린 뒤 10초는 다시 걸리지 않고, 토너먼트에서는 걸리지 않는다.
- 화면에는 왼쪽 위에 "공포! 용병이 도망칩니다 (n초)"가 뜨고, 도망치는 용병 머리 위에 느낌표가 뜬다. 지속 시간(`SHAKEN_SEC`)과 도망 속도(`SHAKEN_FLEE_SPEED`)는 수치 조정 도구에 있다.

### 우클릭 기병 지시: 이동 / 공격
- 마우스 **우클릭**으로 기병 용병에게 지시한다(주인공 기준 900px까지). **빈 땅**을 찍으면 **이동 지시**: 기병이 싸우지 않고 그곳까지 가서 자리를 지키며(`MOVE_ORDER_SEC` 12초), 도착하면 지점 주변(`MOVE_ENGAGE_RADIUS` 150px)에 온 적과만 싸운다. **적 주변**(`ORDER_ATTACK_PICK` 90px 안에 적이 있는 곳)을 찍으면 **공격 지시**: 기존 돌격처럼 그 일대(반경 300px)의 적을 6초 동안 공격한다. 지점에는 이동은 하늘색 "이동", 공격은 주황색 "공격" 표시가 뜬다. 서버는 `charge` 메시지로 같은 좌표만 받고 종류(`PlayerState.chargeKind`)를 정한다. 다른 병종은 영향을 받지 않는다.

### 체력 재생·흡혈 너프(대신 더 자주), 주인공 호위 AI, 맵 경계
- **체력 재생**: 한 장의 효과를 낮췄다(주인공 초당 +0.2 → +0.12, 용병 초당 최대 체력 +0.4% → +0.25%). **흡혈**: 전설 피의 갈증을 준 피해의 4% → 2.5%로 낮추고, 새로 **흡혈 카드**(주인공·기병·창병·검방병·둔기병 전용, 일반 +1.2% / 희귀 +1.9% / 영웅 +2.9%)를 넣었다. 두 카드는 뽑힐 확률 가중치를 올려(5 → 9) 더 자주 나오고, 피의 갈증 전설도 더 자주 나온다(가중치 0.6 → 1.6). 능력치 상자에 `흡혈`이 표시된다.
- **캠프 고용창**은 화면 **오른쪽 위**에 뜬다. 레벨업 카드가 함께 떠 있으면 카드를 그 아래로 내린다.
- **마법사 선딜(주문 시간) 2초**(용병·주인공 지팡이). 적 마법사는 3.5초 그대로다. 운석이 떨어지는 연출은 폭발 약 0.6초 전부터 시작한다(서버가 주문 시간을 함께 보낸다).
- **주인공 호위 AI 개선**: ① 진형 자리에서 벗어나 적을 쫓을 수 있는 거리를 1.8배(`DEFEND_LEASH_MULT`)로 늘렸다(기병 제외). ② 주인공 둘레 `GUARD_HERO_RADIUS`(260px) 안의 적은 진형 자리에서 멀어도 막으러 나선다. ③ 진형 자리에서 뒤처졌을 때 따라붙는 속도를 거리에 비례해 올렸다(`CATCHUP_MAX` 3.2배까지). ④ **뒤처져 있어도 바로 곁(사거리 안)의 적과는 맞서 싸운다**(전에는 자리로 돌아가는 데만 몰두해 맞고만 있었다). 같은 조건 시뮬레이션에서 "적이 90px 안인데 가만히 서 있는 비율"이 36% → 20%로 줄었다.
- **맵 경계**: 용병·적·주인공이 밀리거나 쫓기거나 진형 자리가 맵 밖이어도 매 틱 경계 안으로 되돌린다.

- **둔기 너프**: 둔기병 용병 공격력 45→36, 주인공 철퇴 34→27(-20%), 대신 방패에 대한 배율을 250%→300%로 올려 방패 상대로는 오히려 조금 더 세다(방패 상대 실효 피해: 용병 112→108, 주인공 85→81). 방패 없는 상대에게는 -20%.

- **자리 비움 연결 끊기(업데이트 방해 방지)**: 로비·대기실·결과 화면에서 5분(`IDLE_KICK_SEC`) 동안 키·마우스·터치 입력이 없으면 서버가 연결을 끊는다. 창을 안 끄고 둔 접속 때문에 자동 업데이트(접속자 0명을 기다린다)가 계속 밀리지 않게 하려는 것이다. 클라이언트는 입력이 있으면 20초에 한 번 `active`를 보낸다. **게임이 진행 중인 방은 아무리 가만히 있어도 끊지 않는다.** 끊긴 화면은 자동으로 재접속하지 않고 새로 고치라는 안내를 띄운다.

- **병종 선택과 단축키(고정 번호)**: **1** = 모든 병종, **2 기병 · 3 창병 · 4 궁병 · 5 검방병 · 6 둔기병 · 7 마법사**. 캠프 곁에서는 그 번호가 그 병종을 **고용**(캠프가 파는 병종일 때)하고, 아니면 그 병종을 **선택**한다(Shift+번호는 해고). 캠프 고용 창에도 병종마다 고정 번호가 표시된다. 선택한 병종(기본은 전체)은 하단 범례가 노랗게 되고, 일부만 선택하면 그 용병 발밑에 노란 고리가 그려진다.
  - **우클릭**: 선택한 병종에게 지시한다. 빈 땅이면 이동(12초), 적 근처면 공격(6초, 적을 150px 안쪽으로 넉넉하게 찍어도 가장 가까운 적을 쫓는다). 이동 지시를 받은 병종은 그 지점 둘레에 흩어져 서며 가까운 적과 싸우고, 공격 지시는 그 적 일대를 쫓는다.
  - **F1·F2·F3·V·T(진형 명령)도 선택한 병종에게만** 적용된다(병종마다 진형 모드와 지점 방어 지점이 따로 있다). 선택한 병종들의 진형이 서로 다르면 진형 버튼은 모두 꺼져 보인다.
- **월드 경계 밖**: 바닥 타일을 경계 밖 1800px까지 깔고 경계 밖은 어둡게 눌러서, 가장자리로 가도 화면이 검게 비지 않는다.
- **유닛 겹침 방지**: 적끼리(즉시), 아군 용병끼리(부드럽게)에 더해, 적과 아군 용병·주인공이 포개지면 약하게 밀어낸다(`separateCross`, 초당 120px). 주인공은 밀리지 않고 상대가 비켜 준다. 공격 준비 중인 쪽은 제자리를 지킨다. **속도가 0.3 이상 붙은 기병(아군·적)은 돌격 중이라 다른 유닛을 통과한다.**
- **중독 표시**: 독에 걸린 유닛(적, 토너먼트의 용병·주인공)은 몸 전체가 옅은 보라색 막으로 덮인다(같은 모양의 흰 실루엣을 보라색 38%로 위에 씌움, `setPoison`). 서버는 와이어에 중독 여부(`EnemyWire[12]`, `MercWire[18]`, `PlayerState.poisoned`)를 보낸다.
- **독 궁병**: 스테이지 2부터 적 궁병 일부(스테이지당 +8%, 최대 40%, 보스·장군 제외)가 독 화살을 쏜다(`VENOM_*` 튜닝). 맞은 아군(주인공·용병)은 4초간 중독되어 지속 피해를 입고 몸이 옅은 보라색으로 덮이며 보라색 `-N` 숫자가 뜬다. 방패가 막은 화살은 독이 묻지 않는다. 토너먼트의 독 화살과 같은 규칙이다.
- **로딩 화면**: 처음 그림을 모두 불러올 때까지, 그리고 판이 시작될 때 서버가 보낸 지형 그림이 준비될 때까지 불투명한 로딩 화면(`#loading`)이 모든 화면을 덮는다.
- **둔기 추가 하향(-10%)**: 둔기병 용병 36→32.4, 적 둔기병 9.5→8.55, 주인공 철퇴 27→24.3. 경직은 0.3초 + 0.1초×단계(최고 0.7초)로 낮췄다.
- **단계별 병종 특화(체력·공격력 외)**: 기병 이동 속도 +5%와 **돌격 피해 +10%**, 창병 **카운터 피해 +10%**(사거리 보너스는 뺌), 궁병 사거리 **+10%**, 검방병 방패 +15%, 둔기병 범위 +8%·경직, 마법사 **시전 시간 -5%p**(사거리 보너스는 뺌)·폭발 범위 +10%. 단계마다 누적이며 `TIER_*` 상수에 있다.
- **적 기병·창병 공격 범위**: 적 기병은 사거리(46)는 그대로 두고 직사각형 폭을 아군 기병의 절반(반폭 10)으로, 적 창병도 창병 용병처럼 부채꼴이 아니라 앞으로 뻗은 직사각형(사거리 58, 반폭 18)으로 찌른다(`ENEMY_BOX_WIDTH_MULT`). 공격 예고도 같은 모양이다.
- **기병 속도선 없음**: 속도가 붙은 기병 뒤에 그리던 흰 세 줄(속도선)은 없앴다. 달리는 모습은 달리기 프레임과 출렁임으로만 표현한다.
- **기병·창병 폭 통일**: 기병·창병(아군·적, 주인공 창 포함)의 찌르기는 전체 폭 30(반폭 15) 직사각형이고, 기병 사거리는 약 10% 늘렸다(아군 53, 적 51). 적 기병·창병의 폭 배율은 모두 1이다.
- **사거리 조정**: 적 마법사 280→260, **적 창병 58→90**(창병 용병은 100 그대로), 주인공 활 520→400. **주인공 기마**는 용병·적 기병처럼 부채꼴이 아니라 전체 폭 30의 직사각형이고 사거리는 54→65(범위 카드는 폭을 넓힌다). 주인공 창(112)과 창병 용병(100)은 그대로다.
- **적 창병 카이팅**: 적 창병은 목표에서 사거리의 절반 거리(사거리 90이면 약 45px+반지름)에 서려고 하며, 그보다 가까워지면 물러나며 찌른다. 이동 속도가 근접 용병보다 빨라서(약 98 대 75~80) 근접 용병이 쫓아도 거리를 유지할 수 있다. 상대하려면 궁병·마법사나 기병, 또는 둔기 경직·넉백이 필요하다.
- **용병 이동 속도 조정**: 궁병 95→85, 검방병 90→80, 마법사 60→65. (기병 300, 창병 95, 둔기병 75는 그대로.) 모든 값은 `MERC_STATS`의 `speed`다.
- **통솔력 % 카드**: 일반/희귀/영웅이 각각 통솔력 +10%/16%/24%(레벨 3부터)이다. (시작 5 + 카드로 얻은 고정 증가)에 쌓인 비율을 곱하고 반올림한다. 통솔력이 클수록 효과가 커서 후반에 유리하다.
- **용병 수 상한 제거**: 용병 16명 제한(`MAX_MERCS_PER_PLAYER`)을 없앴다. 이제 통솔력만이 용병 수를 제한한다. 용병이 많아지면 서버·화면 부담이 커질 수 있다.
- **토너먼트 예고**: 3·6·9·10스테이지에서 보스를 잡으면 바로 시작하지 않고 `TOURNAMENT_NOTICE_SEC`(15초) 동안 예고한다. 위쪽 문구에 "토너먼트가 N초 뒤에 시작됩니다"가 뜨고, 처음에 경고음과 안내(남은 적과 캠프가 사라진다)가, 마지막 5초는 매 초 카운트다운이 뜬다. 예고 중에는 휴식 시간이 끝나도 다음 스테이지로 넘어가지 않고 보상·상자·부활은 그대로 받는다.
- **쓰러져도 우클릭 지시**: 주인공이 쓰러져 있거나 관전 중이어도 우클릭 이동·공격 지시를 줄 수 있다. 지시 지점은 화면에서 가리킨 **절대 월드 좌표**로 보내며(카메라가 어디를 보든 상관없음), 주인공과의 거리 제한(`CHARGE_MAX_DISTANCE`)은 없앴다. 월드 밖만 안으로 맞춘다.
- **토너먼트 경기장 확대**: 경기장 반지름 800→1950(지름 1600→3900, 약 2.4배), 두 선수의 시작 거리 520→1270. 월드가 4000×4000이라 3배(지름 4800)는 월드를 넘어서 월드가 허락하는 최대에 가깝게 잡았다. 월드를 더 키우면 더 넓힐 수 있다.
- **맞는 소리 줄이기**: 피격음(근접 피격·내 유닛 피격·적 화살 명중·방패 막음)은 최근 1초 동안의 피격 수에 비례해 소리 사이 간격을 늘린다(0.07초~0.9초). 많이 맞을 때 소리가 겹쳐 시끄럽지 않다.
- **공격 지시(무리 단위)**: 우클릭으로 적을 가리키면 그 한 마리가 아니라 둘레 `ORDER_GROUP_RADIUS`(240px) 안의 **무리 전체**가 대상이다. 지시 지점은 그 무리의 중심이고 무리가 움직이면 따라가며(한 마리를 쫓아 돌아가지 않는다), 각 병종은 그 안에서 평소 AI의 상성대로 적을 고른다(기병은 궁병·둔기병 먼저, 창병은 피함 등). 무리가 사라지면 곧 풀린다. 쓰러져도 지시는 유지된다.

- **효율 고정(상한 없음)**: 방어력·회피율·부활 속도는 쌓을수록 효율이 커지지 않도록 합계 x를 **체력 증가와 같은 효율**로 환산한다(리그 오브 레전드 방식). 받는 피해 = 1/(1+x)배, 회피 확률 = x/(1+x), 부활 시간 = 1/(1+x)배. 카드 한 장은 언제 얹어도 유효 체력 +그 값만큼의 이득이다(예: 방어력 +4% 카드 = 체력 +4%). 방어력 60%·회피 50% 상한은 없앴고, 부활 시간 카드는 **부활 속도**(+37.5% 등)로 바뀌었다. 화면의 방어력·회피율은 실제로 줄어드는 비율/확률로 표시한다. 피해 감소(고정치) 상한(70%)과 치명타 상한은 그대로다.
