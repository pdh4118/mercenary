# Mercenary (머서너리)

용병을 고용해 주변에 배치하며 싸우는 뱀서류 멀티플레이(6인 이상) 게임.

## 구조

- `shared/` - 서버·클라이언트가 함께 쓰는 규칙과 프로토콜 (TypeScript)
- `server/` - 전투를 계산하는 권위 서버 (Node.js + ws, 초당 20틱)
- `client/` - 화면과 입력 (PixiJS + Vite). 입력만 보내고 서버 결과를 그린다

## 실행

```sh
npm install
npm run dev:server   # ws://localhost:8080
npm run dev:client   # http://localhost:5173
```

같은 서버에 여러 탭으로 접속하면 멀티플레이를 확인할 수 있다. 이름은 `?name=이름`, 서버 주소는 `?server=ws://호스트:포트`로 지정.
조작: WASD/방향키 이동, 마우스로 조준, 마우스 버튼(또는 스페이스)을 누르고 있으면 발사, 캠프 근처에서 1~3 키로 용병 고용.

## 검사

```sh
npm run typecheck
npm test
```

## 규칙 요약

- **적의 공격은 모션이 있다.** 닿는다고 피해를 입지 않고, 공격 예비 동작(빨간 부채꼴/선 표시)이 끝나는 순간 그 범위 안에 있으면 맞는다. 피하면 안 맞는다.
- **병종 5종**(기병·창병·궁병·검방병·둔기병)은 적과 용병 모두 같다. 상성은 기병<창병<궁병<검방병<둔기병(왼쪽이 오른쪽에게 약함)이고, 기병은 창병 말고는 전부에게 강하다. 배율은 `shared/src/rules.ts`의 `COUNTER_MATRIX`.
- **용병**은 주인공 주변 진형 자리(앞줄 검방·둔기 / 중간 창·기병 / 뒷줄 궁)를 따라다니며 자동으로 싸운다. 각자 체력이 있고, 쓰러지면 15초 뒤 주인공 곁에서 부활한다.
- **캠프**가 무작위로 생기고, 적을 잡아 모은 금화로 용병을 고용한다(보유 수가 늘수록 비싸짐, 최대 8명).

## 현재 상태

프로토타입 3단계: 적 병종과 공격 모션, 용병 고용·진형·상성, 캠프.
수치(체력·피해·가격·스폰량)는 임시값이며 아직 밸런스를 잡지 않았다.

다음: 용병 비용(통솔력)과 기병의 측면 기동 → 주인공 무기 변경 → 레벨업 선택지 3종.
