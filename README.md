# Mercenary (머서너리)

용병을 고용해 주변에 배치하며 싸우는 뱀서류 멀티플레이(6인 이상) 게임.

## 구조

- `shared/` - 서버·클라이언트가 함께 쓰는 규칙과 프로토콜 (TypeScript)
- `server/` - 전투를 계산하는 권위 서버 (Node.js + ws, 초당 20틱)
- `client/` - 화면과 입력 (PixiJS + Vite). 입력만 보내고 서버 결과를 그린다

## 실행

```sh
npm install
npm run dev:server   # ws://localhost:8080
npm run dev:client   # http://localhost:5173
```

접속하면 로비가 나온다. 같은 서버에 여러 탭으로 접속하면 멀티플레이를 확인할 수 있다.
서버 포트는 환경 변수 `PORT`(기본 8080)로 지정한다. 개발 서버(5173)는 `/ws`를 게임 서버(8080)로 넘겨 준다. 다른 서버에 붙으려면 `?server=ws://호스트:포트/ws`.
`?name=이름`을 붙여 열면 로비를 건너뛰고 바로 빠른 시작하고, `?name=이름&room=코드`면 그 방에 바로 참가한다(링크 공유·테스트용).
조작: WASD/방향키 이동, 마우스로 조준, 마우스 왼쪽 버튼(또는 스페이스)을 누르고 있으면 발사, 우클릭은 기병 돌격 지시, 캠프 근처에서 1~3 키로 용병 고용·Shift+1~5로 해고, 레벨업 카드는 Z/X/C, 무기 전환은 Q 또는 마우스 휠.

## 규칙 요약

- **적의 공격은 모션이 있다.** 닿는다고 피해를 입지 않고, 공격 예비 동작(빨간 부채꼴/선 표시)이 끝나는 순간 그 범위 안에 있으면 맞는다. 피하면 안 맞는다.
- **병종 5종**(기병·창병·궁병·검방병·둔기병)은 적과 용병 모두 같다. 상성은 "몇 % 강하다"가 아니라 구체적인 규칙이다. 수치는 `shared/src/rules.ts`.
  - **검방병**: 몸 체력과 별개로 **방패 체력**이 있고, **정면(좌우 70도)에서 오는 공격만** 방패가 흡수한다. 옆·뒤에서 맞으면 방패를 무시한다. 방패에는 화살 25% · 기병 돌격 50% · 창 60% · 검 100% · **철퇴 250%**로 들어가 궁수에게는 오래 버티고 둔기병에게는 취약하다. 방패가 깨지면 8초 뒤 재생되고, 깨진 동안은 정면 흡수가 사라질 뿐 별도의 취약 배율은 없다(짧은 사거리와 낮은 공격력이 약점).
  - **둔기병**: 방패 특화(250%)와 작은 **범위 공격**(맞힌 대상 주변 46px의 다른 적에게 절반 피해).
  - **기병**: 움직이면 속도가 점점 붙어(약 2초에 최대) 공격에 **속도에 비례한 돌격 피해**가 더해진다. 공격하면 속도를 잃는다. 옆·뒤로 돌아 방패를 우회하고 궁병·둔기병을 노린다.
  - **창병**: 돌격 피해를 받지 않고 **그대로 기병에게 되돌려준다.** 근접 사거리가 가장 길다(창병 > 둔기병 > 검방병).
  - **궁병**: 사거리가 길지만 방패 정면에는 거의 막힌다.
- **피해 숫자**: 내 주인공·용병이 적에게 준 피해는 흰 숫자, **치명타는 크고 굵은 금색 숫자(`112!`)**, 적 방패가 흡수한 피해는 작은 하늘색 숫자, 내 유닛이 입은 피해는 빨간 `-숫자`, 회피는 `회피`로 위로 떠오르며 사라진다. 서버가 이벤트(`ev`)로 피해량과 때린/맞은 사람을 알려 주고, 같은 대상에게 한 틱에 들어간 피해는 합쳐서 보낸다. 다른 플레이어의 피해는 띄우지 않는다.
  - **배후 공격**: 방어하는 쪽의 등 뒤(반각 60도)에서 오는 공격은 피해(돌격 피해 포함)가 **1.5배**다. 적·아군 모두에게 적용되고, 유닛은 마지막으로 이동·공격한 방향을 바라본다. 기병이 옆·뒤로 우회하는 이유이자 가장 큰 보상이다(방패는 어차피 정면만 막는다). 아군이 등 뒤를 때리면 주황 사선이 뜬다.
- **진형 편성(B)**: 병종마다 설 구역(전열·중열·후열·좌익·우익·양익·후위 호위)과 간격을 골라 4개까지 저장하고, 전투 중 **F1~F4**(또는 화면 아래 버튼)로 바로 바꾼다. 저장은 브라우저에 하고 접속할 때 서버에 다시 알린다. 로직은 `shared/src/formation.ts`.
- **용병**은 주인공 주변 진형 자리(앞줄 검방·둔기 / 중간 창 / 뒷줄 궁 / 기병은 양옆 날개)를 따라다니며 자동으로 싸운다. 각자 체력이 있고, 쓰러지면 부활한다(기병 40초, 나머지 30초).
- **통솔력**: 용병마다 비용(기병 2, 나머지 1)이 있고, 보유 용병의 비용 합이 통솔력(시작 5)을 넘을 수 없다. 늘리는 방법은 레벨업 선택지(예정).
- **캠프**가 무작위로 생기고, 적을 잡아 모은 금화로 용병을 고용한다(보유 수가 늘수록 비싸짐). 캠프에서는 해고도 되고 지불한 금화의 절반을 돌려받는다.
- **기병**은 자신이 강한 적(특히 궁병)을 먼저 노려 옆·뒤로 돌아 들어가고, 창병 적은 피해 돌며, 공격한 뒤엔 잠깐 물러난다(치고 빠지기). 평소 활동 범위는 넓고, **우클릭으로 돌격 지점을 지시**하면 6초간 그 지점으로 나가 싸운다(체력이 낮으면 자동 복귀).

- **경험치와 레벨업**: 적을 잡으면 경험치의 50%는 처치한 사람(용병이 잡아도 주인)에게, 나머지 50%는 접속한 모든 플레이어에게 똑같이 나뉜다(뒤처져도 따라갈 수 있게). 레벨업하면 각자 화면에 카드 3장이 뜨고, **게임은 멈추지 않는다**. 키 한 번(Z/X/C)으로 고르고, 시간 제한이 없으며 여러 번 레벨업하면 쌓여서 차례로 뜬다. 카드는 규모(통솔력·고용 할인·전리품) / 용병 강화 / 주인공 강화에서 섞여 나오고, 가진 병종의 단련 카드만 나온다. 카드 목록은 `shared/src/cards.ts`.

- **주인공 무기**: 활(원거리, 방패 정면에는 25%) / 창(긴 찌르기, 기병 돌격 무효·반사, 방패에 60%) / 검(빠른 휘두르기, 정면 피해 절반 방어) / 철퇴(느리고 강함, 방패에 250%, 범위 공격). 병종과 같은 규칙이 무기에 적용되므로 상황에 맞춰 바꾸면 유리하다(화면 오른쪽 아래에 현재 무기의 특징이 표시된다). 무기를 바꾼 직후 0.25초는 공격할 수 없다.
- **카드 등급**: 수치 카드는 같은 능력치라도 **일반 / 희귀 / 영웅**이 있다(효과 x1 / x1.6 / x2.4, 관통·통솔력은 +1/+2/+3). 등급이 높을수록 드물게 나오고(확률 x1 / x0.4 / x0.12) 늦게 나온다(레벨 1 / 3 / 6부터). 카드 테두리 색(회색 / 파랑 / 보라 / 전설 주황)과 별 개수로 구분한다.
- **병종 육성**: 용병 강화 카드의 주력은 **병종 전용 카드**다(기병 체력·공격력·이동 속도·치명타·회피·공격 속도·범위 / 창병 체력·공격력·사거리·방어력·공격 속도·범위 / 궁병 공격력·사거리·공격 속도·치명타·관통 / 검방병 체력·방어력·재생·공격력·부활 단축·공격 속도·범위 / 둔기병 공격력·범위·체력·치명타 피해·공격 속도). 전체 용병 카드는 같은 효과의 **20%**(`GLOBAL_CARD_FACTOR`)라 골고루 키우는 쪽은 약하지만 폭이 넓다. 한 병종을 많이 거느릴수록 그 병종 카드가 더 자주 나온다(최대 2배). 병종 간 상성(방패·돌격·반사·범위)은 그대로 확실하므로 한 병종만 키우면 상성에 막히고, 섞어서 키우면 상성을 메운다.
- **카드 새로고침(R)**: 시작 1회, 카드를 고를 때마다 1회씩 얻는다(최대 5). 지금 제시된 카드 3장을 방금 본 카드와 겹치지 않게 다시 뽑는다.
- **용병 개별 강화(U)**: 용병 한 명씩 5단계(예: 창병 → 장창병 → 중갑 장창병 → 정예 장창병 → 창술 대가)까지 금화로 올린다. 단계마다 체력·공격력이 오르고 병종별 보너스가 붙는다(기병 속도, 창·궁 사거리, 검방병 방패, 둔기병 범위). 강화 즉시 늘어난 체력만큼 회복하고, 해고하면 강화 비용도 절반 환급된다. 수치는 `shared/src/tiers.ts`.
- **물량 vs 정예**: 통솔력은 병종 기본 비용에 **단계마다 +1**(예: 창병 1 → 창술 대가 5, 기병 2 → 6)이고 강화할 때도 +1이 든다. 그래서 통솔력당 전투력은 하급병을 많이 모으는 쪽이 낫다. 대신 **군세**(살아 있는 용병 1명당 공격력 +2.5%, 최대 +40%)는 숫자가 많을 때만 유지되고, 용병이 6명 이상인 부대가 6초 안에 최소 3명이면서 부대의 30% 이상이 쓰러지면 **사기 저하**(8초간 공격력 -20%, 풀린 뒤 10초는 다시 걸리지 않음)가 걸려 광역 피해나 큰 피해에 무너지기 쉽다(작은 부대에는 걸리지 않는다. 상태는 화면 왼쪽 위에 표시). 정예는 사거리·속도·방패 같은 단계 보너스와 적은 숫자로도 버티는 개별 전투력이 장점이다. 수치는 `shared/src/tiers.ts`.
- **캠프 고용 단계**: 시간이 지날수록(240초마다 최고 단계 +1, 최대 5단계) 캠프에 높은 단계 용병이 섞여 나오고, 가격은 하나씩 강화하는 비용의 합 + 20%(2단계 x2.64 ... 4단계 x16.2)로 비싸다. 높은 단계 용병은 부활도 단계마다 15%씩 오래 걸린다(기본: 기병 40초, 나머지 30초).
- **용병 이름과 경험치**: 용병마다 "수식어 + 이름"(예: 붉은 카일)이 무작위로 붙고, 같은 주인의 용병끼리는 겹치지 않는다. 용병은 자기 경험치를 가지며, 피해를 주거나 받을 때 조금씩, **막타를 치면 많이**(14, 보스 x4) 오른다. **경험치를 다 채워야만 강화 버튼이 뜬다**(필요량 40/80/140/220, 금화도 필요). 채우면 알림이 뜨고 머리 위에 노란 화살표가 생긴다. `N`을 누르면 모든 용병의 이름이 보인다.
- **전설 능력(카드 분류 "전설")**: 드물게(가중치 0.6, 레벨 6부터) 나오고, 같은 (능력, 대상) 조합은 한 번만 고를 수 있는 시너지 카드. **적용 대상이 정해져 있다**: 주인공만, 또는 특정 병종만(양쪽에 겹쳐 적용되지 않는다). 예: 주인공 처형 / 창병 처형 / 둔기병 처형, 궁병 폭풍 연사, 기병 돌격 가속, 검방병 불사. 능력은 폭풍 연사(치명타 시 대기시간 제거), 피의 갈증, 관통 증폭, 처형, 가시 갑옷, 돌격 가속, 불사, 광역 증폭, 전장의 함성(대상이 처치하면 그 대상의 공격 속도 중첩). 대상 목록과 수치는 `LEGENDS`·`LEGEND_CONST`(`shared/src/cards.ts`).
- **난이도와 레벨 주기**: 적 생성량(+22%)과 스테이지별 체력 성장(+22%)을 올려 기본 난이도를 높였고, 레벨업 필요 경험치를 12 + 9 x (레벨-1)로 낮춰 카드가 잦게 나온다.
- **경제·성장 카드(규모 분류)**: 전리품(처치 금화 +25/40/60%), **보상금**(스테이지·소대 클리어 금화 +30/48/72%), **경험치**(주인공 경험치 +15/24/36%), 병종별·전체 **용병 경험치 획득**(용병이 빨리 강화 가능해짐), **행운**(+20/32/48%): 행운 1.0마다 희귀 x4, 영웅 x7, 전설 x9 배율로 높은 등급 카드가 잘 뜬다(일반은 그대로, 상한 3.0). 행운은 화면 왼쪽 위에 표시된다.
- **넉백 카드**: 주인공용(일반 +30 / 희귀 +48 / 영웅 +72)과 기병·창병·검방병·둔기병 전용, 전체 용병용(효과 20%)이 있다. 맞은 적은 공격해 온 반대쪽으로 그만큼(px) 밀려나고, 하던 공격 동작이 끊기며 0.4초간 공격하지 못한다. 보스는 25%만 밀린다(상한 160px). 화살도 날아온 방향으로 민다.
- **공격 능력치 카드**: 공격력, 사거리, 관통(화살이 적을 더 뚫음), 치명타 확률(상한 75%, 기본 피해 x1.5), 치명타 피해, 범위(근접 부채꼴·범위 공격 반경)가 주인공용·용병용으로 각각 있다. 치명타는 공격 한 번에 한 번 판정하고 노란 별로 표시된다. 궁병 관통 카드는 궁병이 있을 때만 나온다.
- **생존 능력치 카드**: 방어력(받는 피해 감소, 상한 60%), 회피율(공격을 완전히 피함, 상한 50%, 흰 고리로 표시), 체력 재생(주인공은 초당 고정량, 용병은 최대 체력 비율), 최대 체력이 주인공용·용병용으로 있다.
- **레벨업 순간**에는 주변(240px) 적이 밀려나고 잠깐(0.8초) 공격하지 못한다. 카드를 고를 틈을 주기 위함.

- **목표는 스테이지 10.** 스테이지마다 **3분의 자유 성장 시간**(일반 적이 계속 나오고, 캠프·레벨업으로 키운다) 뒤에 **보스군**이 먼 곳에서 진형을 갖추고 행군해 온다. 장군이 쓰러지면 클리어(금화·경험치 보상, 쓰러진 동료 자동 부활, 10초 휴식)이고 다음 스테이지로 간다. 스테이지가 오를수록 적의 체력·피해·생성량이 늘어난다. 10스테이지 장군을 잡으면 승리.
- **적 소대**: 보스가 아닐 때도 성장 단계에서 가끔(첫 소대는 스테이지 시작 30초 뒤, 이후 약 40초 간격, 스테이지가 오를수록 짧아짐) **소규모 혼성 부대**가 진형을 갖추고 다가온다. 병종끼리 서로의 약점을 가려 주도록 짜여 있다: 방패 벽(검방병이 화살을 막고 궁병이 뒤에서 쏨) / 창 방진(창병이 돌격을 막고 검방병·궁병이 받침) / 기마 돌격(기병이 우회하는 동안 궁병·검방병이 정면을 잡음) / 파쇄조(둔기병이 방패를 부수고 창병이 옆을 지킴) / 혼성 돌파. 규모는 4 + 스테이지 + 인원 x 0.8(최대 14). 병사는 보스군처럼 진형 자리를 지키며 행군하다가 가까워진 아군만 쫓는다. 전멸시키면 병사 1명당 4G를 모두가 받고, 화면 위에 소대 수가 표시된다. 구성은 `server/src/stage.ts`의 `SQUAD_KINDS`.
- **보스군**: 병력은 (10 + 6 x (스테이지-1)) x 접속 인원^0.8(최대 260). 앞줄 검방병 → 창병 → 둔기병 → 장군 → 궁병 순으로 줄을 서고, 기병은 양옆 날개에 선다. 장군은 스테이지마다 병종이 다르고(검방·창·기병·둔기·궁) 크고 튼튼하다. 병사는 진형 자리를 지키며 천천히 전진하다가, 가까이 온 아군만 쫓고(너무 멀어지면 자리로 복귀) 싸운다. 수치는 `shared/src/rules.ts`의 STAGE_*/ARMY_*/BOSS_*, 진형 계산은 `server/src/stage.ts`.
- **쓰러짐과 부활**: 주인공의 체력이 0이 되면 쓰러져 움직이지 못하고(용병은 계속 싸운다), 동료가 곁(70px)에서 **E를 5초간 누르고 있으면** 체력 절반으로 일어나 2초간 무적이다. 중간에 멈추거나 떨어져도 진행도가 한 번에 사라지지 않고 채울 때의 4분의 1 속도로 조금씩 줄어들어, 다시 시작하면 이어서 채운다. **모든 주인공이 쓰러지면 게임오버.** 혼자 하면 쓰러지는 즉시 끝이다.
- **명중 알림**: 화살 명중·방패 막힘/깨짐·부활은 서버가 이벤트(`ev`)로 알려 주고, 클라이언트는 그대로 그린다(추정하지 않음).
- 시험 플레이용으로 서버를 `MERC_STAGE_GROW_SEC=20`처럼 띄우면 성장 시간이 줄어 보스군을 빨리 볼 수 있다.

## 소리

소리 재생 코드는 들어 있고, **파일이 없으면 조용히 건너뛴다**(지금은 파일이 없다). `client/public/assets/audio/`에 `<이름>_<번호>.ogg`(또는 `.wav`, `.mp3`)로 넣으면 바로 나온다. 이름·제작 문구는 `docs/asset-prompts.md` 10장, 음량·간격·동시 개수는 `shared/src/audio.ts`.

- **연결된 소리**: 화살 발사·명중, 근접 타격, 방패 막힘·깨짐, 치명타, 배후 공격, 넉백, 회피, 적 처치, 무기 휘두르기, 피격, 레벨업, 카드 선택·새로고침·전설, 금화, 고용, 강화 가능·완료, 쓰러짐·부활(진행 중 반복음 포함), 사기 저하, 소대·보스 경고, 스테이지 클리어·승리·패배, 캠프 진입, 버튼 클릭, 기병 돌격·질주, 배경 음악(로비 / 성장 / 보스).
- **자연스럽게 들리도록**: 같은 소리는 최소 간격과 동시 개수를 제한하고(전체 28개), 변형이 여러 개면 번갈아 틀며 음높이를 조금씩 흔든다. 위치가 있는 소리는 내 주인공과 멀수록 작아지고 좌우로 치우친다(950px 밖은 들리지 않음). 알림 소리(레벨업 등)는 제한 없이 항상 난다.
- **설정**: 오른쪽 위 스피커 버튼 또는 `M`으로 음소거, `Esc` 방 메뉴에서 효과음·음악 음량. 설정은 브라우저에 저장된다. 브라우저 정책상 **첫 클릭이나 키 입력 뒤부터** 소리가 난다.
- 서버가 알려 주는 이벤트(`ev`)에 맞춰 소리를 내므로, 화면에서 보이는 것과 소리가 어긋나지 않는다.

## 방 관리

- **로비**: 방 목록(실시간 갱신, 대기 중/진행 중 표시), 빠른 시작(공개 방 중 사람이 많은 곳, 없으면 새로 만들어 바로 시작), 방 만들기(공개/비공개), 4글자 코드로 참가.
- **비공개 방**: 목록과 빠른 시작에 나오지 않고 코드를 아는 사람만 들어온다. 같은 주소에서 코드를 8번 연속 틀리면 60초 동안 참가 시도를 막는다(무작위 대입 방지). 프록시/터널 뒤에서는 `TRUST_PROXY=1`이 필요하다(`docs/deploy.md`).
- **대기실**: 방을 만들면 대기실에서 시작한다. 참가자는 "준비"를 누르고 방장은 접속 중인 모두가 준비하면 "게임 시작"을 누른다(혼자서도 시작 가능). 시작 전에는 게임이 진행되지 않고 조작도 받지 않는다. 시작한 뒤에는 새로 들어와도 준비 없이 바로 합류한다. 연결이 끊긴 사람은 시작을 막지 않는다.
- **게임이 끝나면**(승리/전멸) 결과 화면(스테이지·시간·플레이어별 레벨/처치/부활시킴)이 뜨고, 방장이 "다시 하기"를 누르면 같은 참가자로 대기실에 돌아간다. 끝난 방에는 새로 들어올 수 없다.
- 방마다 **독립된 판**이고 최대 8명, 서버 전체 방은 30개까지. 아무도 없는 방은 사라진다.
- **방장**은 처음 만든 사람이고, 다른 참가자를 내보낼 수 있다. 방장이 나가면 다음 사람에게 넘어간다. `Esc`로 방 메뉴(코드·참가자·내보내기·나가기)를 연다.
- **접속이 끊겨도 30초**는 자리를 지킨다. 그 안에 같은 브라우저 탭에서 다시 접속하면(새로고침 포함) 같은 캐릭터·용병·금화로 이어서 한다. 기다리는 동안 주인공은 제자리에 서고 적의 목표가 되지 않으며, 용병은 계속 싸운다. 30초가 지나면 방에서 빠진다.
- 서버는 메시지 크기(2KB)와 빈도(초당 120회)를 제한하고, 응답 없는 연결은 주기적으로 확인해 정리한다. 방 로직은 `server/src/rooms.ts`.

## 배포

`npm run build && npm start` 하나로 서버가 화면과 접속(`/ws`)을 같은 포트에서 제공한다. 메시지는 압축되어 약 1/3로 전송된다. 호스팅 선택(개인 서버 + Cloudflare Tunnel 추천 / 포트포워딩 / VPS), 필요한 대역폭 실측, Docker·systemd 예시는 [`docs/deploy.md`](docs/deploy.md).

## 밸런스 점검

`npm run balance -w server -- <초> <인원 목록> <시드 수>` (예: `-- 2100 1,3,6 3`, 10스테이지는 약 2000초). 봇이 끝까지(승리·전멸·시간 초과) 플레이하는 판을 서버 로직 그대로 돌려 도달 스테이지, 주인공·용병 쓰러짐, 부활, 레벨을 뽑는다. 봇은 사람보다 훨씬 서툴러서 절대 기준이 아니라 변경 전후 비교용이다. `RESPAWN_SCALE=0.67`처럼 주면 용병 부활 시간을 그 배율로 바꿔 비교할 수 있고(출력에 "용병 쓰러져 있는 시간%"가 나온다), `DETAIL=1`을 붙이면 병종별 쓰러짐도 나온다. 수치를 바꾼 뒤 이걸로 확인한다.

## 에셋

스프라이트는 `client/public/assets/`에 있다: 병종 유닛(`units/`), 주인공 무기별 포즈(`hero/`), 캠프(`camp/`), 바닥 타일(`tiles/`), 화살(`fx/`). 이미지 도구: 시트를 한 장씩 자르는 `tools/slice_sheet.py`, 흰 배경(가짜 투명 포함)을 투명으로 바꾸는 `tools/remove_bg.py`, 바닥 타일 이음새 검사 `tools/tile_preview.py`(사용법은 각 파일 머리말과 `docs/asset-prompts.md`). 남은 에셋(카드 아이콘, 무기·HUD 아이콘, 효과음)의 제작 프롬프트는 `docs/asset-prompts.md`.

레벨업 카드는 시안(`client/public/assets/cards/art_*.png`, 병종 5종 일러스트)을 반영했다. 병종 단련·용병 체력/공격/속도·주인공 사격 카드는 이 그림을 쓰고, 나머지 카드(통솔력·가격·전리품 등)는 글자 아이콘이라 전용 일러스트가 더 필요하다. 별은 등장 확률이 낮을수록 많다.

이미지·소리 생성 AI나 아티스트에게 의뢰할 때 쓰는 프롬프트: [`docs/asset-prompts.md`](docs/asset-prompts.md)

## 현재 상태

프로토타입 11단계: 적 병종과 공격 모션, 용병 고용·진형·병종 규칙(방패·돌격·반사·범위), 캠프, 통솔력·해고, 기병 운용과 우클릭 돌격, 경험치 공유와 레벨업 카드, 주인공 무기 변경, 임시 밸런스, 병종 스프라이트, 방 관리(로비·방장·재접속·비공개 방·대기실), 주인공·캠프·바닥·화살 에셋, 스테이지 10 + 보스군 + 부활·게임오버·결과 화면, 서버 명중 이벤트.
수치(체력·피해·가격·스폰량·경험치)는 임시값이다. 봇 시뮬레이션으로 1차 조정만 했고 실제 플레이로 다듬어야 한다.

다음: 실제 플레이로 밸런스 조정, 남은 에셋(카드·무기·HUD 아이콘) 교체, 효과음, 서버 배포.
