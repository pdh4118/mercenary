# 효과음·음악 폴더

`<이름>_<번호>.ogg` 형식으로 넣으면 게임이 알아서 불러옵니다(`.wav`, `.mp3`도 가능). 예: `arrow_hit_1.ogg`, `arrow_hit_2.ogg`.
이름 목록과 제작 문구는 `docs/asset-prompts.md` 10장, 코드 쪽 설정(음량·간격·동시 개수)은 `shared/src/audio.ts`.
파일이 없는 소리는 조용히 건너뜁니다.

## 출처 기록 (공개 전에 확인)

| 소리 | 만든 곳 | 요금제 | 비고 |
|---|---|---|---|
| `meteor_fall_1.ogg` (마법사 메테오 소리) | 일레븐랩스(ElevenLabs) 효과음 생성 | **무료** | **이미 게임에 들어 있는 소리.** 무료 요금제는 상업적 이용이 안 되고 출처 표기가 필요하다고 알고 있음(약관 확인). 공개 전에 유료 요금제로 다시 만들거나 교체한다 |
| `skill_*` (스킬 효과음 12종: 후퇴·돌진·무적 켜짐·철퇴 던지기·철퇴 착탄·방벽 생성·방벽 사라짐·방벽 막기·가속 시작·준비 완료·가속 종료·무적 종료) | 일레븐랩스(ElevenLabs) 효과음 생성 | **유료** | 유료 요금제로 만들었다. 약관의 상업 이용 조건은 가입한 요금제 기준으로 확인한다(구독을 해지하기 전에 만든 소리의 사용 권한이 유지되는지도 약관에서 확인) |
| `bgm_lobby_1.ogg` (로비 배경 음악) | 수노(Suno) AI 음악 생성 (`Lute_and_Cello`) | **확인 필요** | 원곡 3분 24초에서 끝의 사라지는 부분을 빼고, 끝 4초를 처음 4초와 같은 전력으로 교차 페이드해 반복 이음새를 맞췄다(192.5초). 음량은 -3dB로 낮춰 다른 배경 음악과 맞췄다. 수노는 무료 요금제 곡의 상업 이용이 안 되는 것으로 알고 있으니 공개 전에 요금제와 약관 확인 |
| 그 밖의 소리 | (기존 파일) | 확인 필요 | 출처를 아직 적지 않았다. 만든 곳과 라이선스를 이 표에 채운다 |


> **파일 이름 주의**: 음악도 효과음과 같은 규칙(`<이름>_<번호>.ogg`)으로 불러온다. `bgm_grow.ogg`·`bgm_boss.ogg`처럼 번호가 없는 파일은 게임이 찾지 못해 지금 재생되지 않는다(`bgm_grow_1.ogg`, `bgm_boss_1.ogg`로 두면 재생된다).
