# 효과음·음악 폴더

`<이름>_<번호>.ogg` 형식으로 넣으면 게임이 알아서 불러옵니다(`.wav`, `.mp3`도 가능). 예: `arrow_hit_1.ogg`, `arrow_hit_2.ogg`.
이름 목록과 제작 문구는 `docs/asset-prompts.md` 10장, 코드 쪽 설정(음량·간격·동시 개수)은 `shared/src/audio.ts`.
파일이 없는 소리는 조용히 건너뜁니다.

## 출처 기록 (공개 전에 확인)

| 소리 | 만든 곳 | 요금제 | 비고 |
|---|---|---|---|
| `skill_*` (스킬 효과음: 후퇴·돌진·무적·철퇴·방벽·가속·준비 완료 등) | 일레븐랩스(ElevenLabs) 효과음 생성 | **무료** | 무료 요금제는 상업적 이용이 안 되고 출처 표기가 필요하다고 알고 있음(가입 때 약관 확인). 돈을 받거나 널리 공개하기 전에 유료 요금제로 다시 만들거나 상업 이용 가능한 소리로 교체한다 |
| 그 밖의 소리 | (기존 파일) | 확인 필요 | 출처를 아직 적지 않았다. 만든 곳과 라이선스를 이 표에 채운다 |
