# 소리 후보 (아직 게임에 쓰지 않은 것)

받은 충격음(impact) 10개를 앞뒤 무음을 자르고 최대 음량을 맞춰 보관한 것입니다. 모두 0.4~0.5초, 3~4.6kHz 중심의 밝은 금속성 타격음입니다.

- 게임에 쓴 것: `impact_8` → `shield_block_2`, `impact_10` → `shield_block_3` (가장 낮고 둔한 쪽을 방패 막힘으로 골랐습니다)
- 남은 것(`impact_1~7, 9`): 치명타(`crit_hit`)나 근접 타격(`melee_hit`) 변형으로 쓸 수 있는 후보입니다. 가장 밝고 짧은 것은 `impact_2`, `impact_7`.

게임이 읽는 폴더는 `client/public/assets/audio/`입니다. 후보를 쓰려면 그 폴더에 `<이름>_<번호>.ogg`로 복사하세요.
