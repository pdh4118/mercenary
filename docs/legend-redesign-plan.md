# 전설 카드 개편 계획

## 1. 목표
- 전설을 "수치가 조금 오르는 카드"가 아니라 **고르는 순간 플레이가 달라지는 카드**로 바꾼다(화면·조작·무기 모양이 바뀜).
- 등장 확률은 지금의 **약 1/3**로 줄인다(드물수록 고를 때 기분이 좋다).
- 두 갈래로 만든다: **변신형**(무기·병종의 방식 자체가 바뀜) / **스킬 강화형**(기존 스킬이 한 단계 다른 물건이 됨).

## 2. 확률 (1단계, 코드 한 줄 수준)
- 지금: 전설 24장, 카드 풀 가중치의 **3.4%**(한 번에 3장 제시 기준 한 장이라도 전설일 확률 약 10%).
- 변경: `legendWeight` 0.6 → 0.2, `bloodthirstWeight` 1.6 → 0.55 → 풀의 **약 1.1%**(3장 제시 기준 약 3.3%).
- 시작 레벨(`legendMinLevel` 6)과 "같은 (능력, 대상)은 한 번만"은 유지.
- 선택 사항: 너무 안 나오면 레벨 15·30에서 전설이 한 장 이상 끼어 나오게 하는 보정(천장).

## 3. 카드 구성 (지금 24장 → 약 18장, 전부 새 효과)
기존 수치형 전설 8종(폭풍 연사, 피의 갈증, 관통 증폭, 처형, 돌격 가속, 불사, 광역 증폭, 전장의 함성)은 모두 아래로 대체한다(남기고 싶은 것이 있으면 알려 주세요).

### 주인공 (무기당 2장: 변신형 1 + 스킬 강화형 1)
| 무기 | 변신형 | 스킬 강화형 |
|---|---|---|
| 활 | **저격수**: 꾹 눌러 모아 쏘는 큰 화살 한 발(관통 무제한, 피해 x4, 사거리 +50%), 연사는 느려진다 | **그림자 사수**: 후퇴 스킬이 3초 투명이 되고, 투명 상태에서 공격해도 풀리지 않으며 첫 발 피해 +50% |
| 창 | **장창 방진**: 창 길이 2배, 앞 직선의 모든 적을 관통, 이동 속도 -15% | **연환 돌진**: 돌진을 1초 안에 3번까지 이어서, 지나간 적을 경직 |
| 검(검방) | **양손검**: 방패를 버린다(방패·막기 사라짐). 대신 검을 양손으로 들어 공격 범위 대폭 증가(사거리 46→80, 부채꼴 75°→140°, 피해 x2.2, 공격 간격 느려짐). 스킬은 무적 대신 **앞쪽 큰 범위 대회전 베기** | **불굴의 진**: 무적 스킬이 내 둘레 큰 원(반경 약 260)의 **광역 무적**(범위 안 아군·용병 피해 무효 2.5초) |
| 철퇴 | **대지의 군주**: 기본 공격마다 작은 충격파, 충격파 스킬은 3연쇄(점점 커짐) | **즉발 지진**: 힘 모으기 없이 즉발, 경직 길게, 쿨타임 절반 |
| 지팡이 | **유성우**: 운석 한 발 대신 3초간 마우스 둘레에 운석이 연달아 떨어짐 | **불꽃 방벽**: 방벽이 2배 길고 통과하는 적에게 지속 피해, 적 화살 반사 |
| 기마 | **돌격 대장**: 가속 중 닿는 적을 밀어내며 관통(속도 안 잃음, 충돌 피해 증가) | **철갑 질주**: 가속 4초 + 그동안 받는 피해 -70% |

### 용병 (병종당 1장, 그 병종 모든 용병에게 적용)
| 병종 | 전설 (종류) | 효과 |
|---|---|---|
| 기병 | **환영 군단** (스킬 강화) | 돌격할 때마다 반투명 흑백 환영 기병이 따라 달리며 같이 들이받는다 |
| 창병 | **방진 창병** (변신) | 서서 싸울 때 사거리 2배·앞 직선 관통, 이동은 느려진다 |
| 궁병 | **그림자 사수** (스킬 강화) | 은신 중 공격해도 풀리지 않고 은신 지속 2배, 쿨타임 감소 |
| 검방병 | **수호 결계** (스킬 강화) | 도발 결계가 **광역 무적 영역**(반경 약 300, 3초)으로 바뀐다 |
| 둔기병 | **지진 군단** (변신) | 모든 공격이 일정 확률로 충격파, 지진 스킬이 연쇄 |
| 마법사 | **연쇄 폭풍** (변신) | 운석이 근처 적으로 연쇄해 번진다 |

## 4. 구현 방식 (코드)
- `shared/src/cards.ts`: `LegendId`와 `LEGENDS`를 새 목록으로 교체. 대상(`scopes`)은 무기(주인공)·병종(용병)으로 그대로. 설명 문구와 수치 상수는 `LEGEND_CONST`로 모아 수치 조정 화면에서 고칠 수 있게 한다.
- 주인공 변신형: 무기 능력치를 계산하는 곳(무기 정의 + 카드 보정)에 전설 분기를 넣는다. 양손검은 방패 관련 로직(막기·방패 체력·재생)을 끄고, 무기 정의(사거리·부채꼴·피해·간격)와 스킬 효과(`useSkill`)를 바꾼다.
- 스킬 강화형: 각 스킬 함수에 분기(예: 무적 범위 확대, 투명 유지)를 추가한다.
- 용병 전설: `mercStats`와 AI·스킬 함수(`stepActives` 등)에 병종별 분기. 기존 승급 스킬 구조(MERC_SKILLS)를 확장한다.
- 시험: 전설마다 서버 시험을 추가한다(효과가 실제로 적용되는지, 대상이 맞는지, 중복 선택이 막히는지).

## 5. "티가 나게" 하는 장치
- 전설 카드 연출: 금색 테두리 반짝임 + 전용 효과음, 고르는 순간 화면 중앙에 큰 글자.
- 주인공 전설을 고르면 몸 둘레에 색 오라(무기별 색), 용병 전설은 해당 병종 발밑 표시.
- 화면 한쪽에 지금 가진 전설 아이콘 줄.

## 6. 필요한 그림·소리 (코드로 만들지 않고 요청)
- 주인공 양손검 전용 그림(방패 없음, 양손으로 든 자세, 남녀 2종 × 공격 자세).
- 대회전 베기 이펙트, 광역 무적 돔, 큰 화살 궤적, 유성우, 불꽃 방벽, 환영 기병(기존 흑백 환영 재사용 가능).
- 전설 카드 일러스트 18장(현재 일부는 글자 아이콘), 선택 효과음.

## 7. 순서
1. **확률 조정 + 카드 규격** (작음): 확률 1/3, 설명·연출 틀.
2. **스킬 강화형 12종** (중간): 그림 없이 가능한 것부터(광역 무적, 은신 유지, 연환 돌진 등).
3. **주인공 변신형 6종** (큼): 양손검처럼 그림이 필요한 것은 그림 요청과 병행.
4. **용병 변신형** (큼): 병종별 AI·스킬 확장.
5. 균형 조정: 전설 하나가 판을 결정하지 않도록 수치 점검, 화면 확인.

## 8. 정해야 할 것
- 기존 수치형 전설 8종을 전부 없애도 되는가(일부 남길지).
- 주인공은 무기당 2장(변신 + 강화)으로 가는가, 1장으로 줄일까.
- 천장(보정) 도입 여부.
- 양손검 그림을 지금 요청할지(요청 문구는 제가 작성).
