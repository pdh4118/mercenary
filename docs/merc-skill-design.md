# 용병 레벨·승급·스킬 설계안 (초안, 아직 구현 전)

## 1. 큰 구조

- **레벨(연속 성장)**: 경험치가 쌓이면 레벨이 오른다. 레벨 1당 체력·공격이 조금씩 늘고 **골드는 들지 않는다.** 초반에 기여를 많이 한 용병이 바로 강해지는 스노우볼.
- **승급(골드)**: 일정 레벨(안: 5·10·15·20)에 도달하면 골드를 내고 승급한다. 지금의 단계 이름(경기병 → 기마병 …)과 강화 비용을 그대로 승급에 붙인다.
- **승급의 경험치 배율은 없앤다**(`MXP_TIER_BONUS` 0). 앞서가는 이점은 레벨에서만 온다.
- **승급 보상은 능력치가 아니라 스킬**: 1단계 패시브 → 2단계 액티브 → 3단계 패시브 → 4단계 액티브. 기본 체력·공격 보너스(`TIER_HP`·`TIER_DMG`)는 크게 줄이고 레벨이 대신 맡는다.
- **액티브는 자동 발동**: 용병은 AI라서 플레이어가 누르지 않는다. 조건이 맞으면(위협 접근, 적 밀집, 체력 낮음 등) 쿨다운마다 스스로 쓴다. 좌측 용병 목록에 스킬 아이콘과 쿨다운을 표시한다.
- **카드와의 관계**: 지금 카드로 나오는 "독 화살" 같은 병종 전용 효과는 승급 패시브로 옮긴다. 카드는 그 패시브를 **강화**하는 것(독 피해 +%, 둔화 시간 +초)으로 바꾼다.

## 2. 병종별 스킬 (1 패시브 · 2 액티브 · 3 패시브 · 4 액티브)

주인공의 스페이스 스킬(후퇴·돌진·무적·철퇴 투척·방벽·가속)과 겹치지 않게 했다. 수치는 제안값이다.

## 3. 유지비(급여)

**측정(스테이지 3, 용병 12명 0단계, 300초)**: 급여 없음 403금화, 지금 급여 393금화 → 5분 급여가 약 10금화(수입의 2.5%)라 사실상 없다. 한 명 1단계 강화(궁병 약 54금화)보다 5분 급여 전체가 싸다.

**안**: `급여 = 통솔력 비용 x 기본계수 x (1 + 0.04 x 레벨 + 0.4 x 승급 단계)` 를 45초마다.
- 기본계수 0.6 → 2.0, 레벨 1당 +4%, 승급 1단계당 +40%.
- 예: 0단계 궁병 Lv1 약 2.1금, 2단계 궁병 Lv10 약 13금, 4단계 궁병 Lv20 약 34금(45초당). 24명이 모두 4단계 Lv20이면 약 800금(45초당)으로 크게 부담.
- 못 낸 급여가 쌓이면 용병이 이탈하는 기존 규칙(`unpaid`)은 유지.
- 최종 계수는 실제 플레이 수입(주인공이 싸우는 경우)과 비교해 시뮬레이션으로 정한다.

## 3-1. 카드 정리(결정)

- "독 화살" 카드는 없애지 않고 **"독 강화"**(독 피해 +%, 지속 +초)로 바꾼다. 3단계 얼음 화살에는 **"둔화 강화"** 카드를 둔다. 해당 승급 전에는 그 카드가 나오지 않는다.

## 4. 구현 순서(권장)

1. 벤치(`snowbench`)에 레벨 모델을 붙여 레벨당 성장률을 정한다(지금 강도와 비슷하게).
2. 레벨·승급 구조와 UI(용병 목록·결과 화면)를 먼저 넣는다(스킬 없이 능력치만).
3. 패시브를 병종별로 하나씩 넣고(카드 이관 포함) 시험을 쓴다.
4. 액티브를 병종별로 하나씩 넣는다(자동 발동 AI, 쿨다운 표시, 효과 그림·소리는 에셋 요청).
5. 유지비를 조정한다.

## 구현 진행 기록

### 1단계: 레벨 모델(꺼짐 상태로 들어감, `TUNE.LV_MODE`)
- 레벨 = 누적 경험치(쓰지 않고 쌓임). 레벨 L→L+1 필요량 = `LV_XP_BASE(60) + LV_XP_STEP(4) × L`, 최고 `LV_MAX(20)`, 총 1960.
- 레벨마다 체력 ×1.061, 공격력 ×1.047(복리). 20레벨이면 체력 ×3.3, 공격력 ×2.5 — 지금 4단계와 같다.
- 승급 가능 레벨 = `LV_PROMO_EVERY(5) × (단계+1)`, 금화·통솔력만 쓰고 경험치는 줄지 않는다. 승급 경험치 보너스는 레벨 모드에서 없다.
- `LV_TIER_KEEP`(0): 단계 표(TIER_HP/TIER_DMG) 반영 비율. 0이면 능력치는 레벨로만 큰다(스킬이 들어오면 이 값을 0으로 굳힌다).
- 측정(snowbench, 스테이지 4, 600초, 3시드): 단계제 평균 단계 1.36(체력 ≈×1.4, 공격 ≈×1.25) vs 레벨제 평균 레벨 5.2(체력 ×1.36, 공격 ×1.27)로 같은 시간 뒤 강도가 비슷하다. 1등 몫 38%→35%, 지니 0.19→0.16으로 쏠림은 조금 줄었다. 승급 경험치 보너스가 없어 총 경험치는 약 20% 적다.

### 2단계: 패시브 스킬 12종(레벨 모드에서만 켜짐)
- 구현 위치: `shared/src/mercskill.ts`(스킬 표·수치 `SK`·`skillOn`), `server/src/game.ts`. 승급 단계 n에 도달하면 n번째 스킬을 얻는다.
- 궁병 독 화살(독 +0.6배)·얼음 화살(적 이동 0.7배 2초, 적에게 둔화 상태 신설), 기병 돌파(돌격 시 다음 적 2명 60%)·철갑마(돌격 중 받는 피해 -25%), 창병 관통 찌르기(창 길이 ×1.25 — 창은 이미 사각형 범위로 여러 명을 꿰뚫으므로 '2번째 적 70%' 대신 길이로 바꿨다)·연속 찌르기(25% 확률로 70% 추가 타), 검방병 가시 방패(막은 피해 25% 반사)·수호(곁 아군 피해 15% 대신), 둔기병 분쇄(방패 있는 적 +30%)·충격파(경직 30% 확률로 곁의 적에게 번짐), 마법사 마력 집중(시전 -15%, 반경 +10%)·불씨(운석 자리 3초 지속 피해).
- 액티브(2·4단계)는 다음 단계.

### 레벨 곡선 재설계(주인공처럼 50~70레벨, 승급 15/30/45/60)
- 사용자 제안: 용병도 주인공처럼 클리어 때 50~70레벨 정도가 되게 하고, 승급은 15·30·45·60레벨에서, 레벨업은 승급 뒤에도 계속된다.
- 값: `LV_PROMO_EVERY 15`, `LV_MAX 75`, 레벨 L→L+1 경험치 `14 + 1.0×L`(60레벨까지 누적 ≈ 2610, 15레벨 ≈ 315), 레벨당 체력 ×1.0201·공격 ×1.0155(60레벨 = 체력 ×3.3·공격 ×2.5, 승급 시점 15/30/45가 예전 1~3단계 배율과 거의 같다).
- 측정(snowbench, 스테이지 4, 600초): 평균 레벨 12~28, 1등 몫 40%(단계제 38%), 둔기병 1명 쏠림이 보여 시드를 늘려 다시 볼 것. 경험치 곡선을 더 가파르게 하면(10+0.8L) 둔기병이 되먹임으로 폭주했다(초당 준피해 185).
- 충격파는 경직이 번지는 적을 가까운 2명, 길이 절반으로 줄였다.

### 전체 판 측정으로 경험치 곡선 재조정(runbench, 용병 6명+60초마다 1명, 보스 150초 제한)
- 경험치 `14+L`은 너무 빨라 최고 용병이 스테이지 5에 72레벨(상한)에 닿았다. `24 + 1.6×L`(60레벨까지 누적 ≈ 4270)로 바꿨다.
- 결과: 스테이지 10 진입 때 평균 레벨 29·최고 74·최저 2, 4단계 승급(60레벨) 도달은 24명 중 약 2.5명(단계제는 약 5명). 앞선 용병은 스테이지 7에 상한에 닿고, 평균 용병은 주인공(50~70레벨)의 절반 정도다.

### 3단계: 액티브 스킬 12종(레벨 모드에서만, 서버 자동 발동)
- `stepActives`가 0.25초마다 상황을 보고 2·4단계 스킬을 쓴다. 쿨다운은 `ACTIVE_CD`([2단계, 4단계]): 궁병 12/20, 기병 14/24, 창병 15/18, 검방병 10/24, 둔기병 14/25, 마법사 14/24. 토너먼트에서는 쓰지 않는다.
- 발동 조건: 뒤로 점프·점멸(적이 110/130 안에 붙음), 은신(사거리 안에 적), 일제 질주(적이 700 안·돌격 속도가 없을 때, 곁 기병 모두 2.5초 가속·돌격 충전), 환영 기병대(적이 600 안 → 그 방향 폭140·길이600 직선의 모든 적에게 기병 공격력 2.4배), 창 던지기(650 안 체력 최대 적에게 3배·방어 무시), 돌진 찌르기(480 안 가장 가까운 적에게 돌진해 2.2배+0.5초 경직), 방패 밀치기(사거리 안 적 밀침·1초 경직), 도발 결계(300 안 적 3명 이상 → 4초간 적이 이 용병을 6배 우선 노림), 도약 내려찍기(460 안 가장 빽빽한 무리에 뛰어들어 반경 140에 2배·0.8초 경직), 지진(적 3명 이상 → 반경 300에 1.2배·1.5초 경직), 연쇄 운석(적 3명 이상 → 서로 떨어진 3곳에 0.5초 간격).
- 은신은 적의 대상 목록에서 빠지는 방식이고, 풀리면 다음 화살 1.8배. 보스는 경직이 30%만 걸린다.
- 클라이언트: `EVT_MERC_SKILL` 이벤트로 스킬 이름 글자와 임시 도형(고리·직선)을 띄운다. 그림·소리 에셋은 별도 요청 예정이다.

### 4단계: 급여(레벨 모드)
- 급여 = `통솔력 비용 × PAY_LV_BASE(1.0) × (1 + 0.04×레벨 + 0.4×승급 단계)` (45초마다, 살아 있는 용병만). 단계제의 `비용×0.6`은 그대로 남아 있다.
- 측정(runbench, 전체 판): 용병 봇의 수입은 분당 150~600금화. 24명이 평균 레벨 33·승급 1.7단계일 때 급여는 살아 있는 용병 기준 45초에 약 100금화(분당 약 130)로 수입의 25~40%, 초반 6명 레벨 3은 45초에 약 13금화(10% 안팎)다. 기본값 2.0은 수입의 80%라 너무 무거워서 1.0으로 정했다. 실제 플레이의 수입은 주인공 처치·줍기가 더해져 더 많으므로, 실플레이 뒤에 계수를 다시 본다.

### 둔기병 경직을 승급 스킬로 옮김(베타 1.320)
- 둔기병 기본 공격의 경직을 없애고 1단계 승급 스킬 "분쇄"로 옮겼다. 분쇄 = 타격이 적을 0.5초 경직(보스는 30%) + 방패·갑옷 있는 적 +30%. 옛 단계제는 0.3초 + 단계당 0.1초(4단계 0.7초)였고, 새 값은 그보다 조금 짧은 0.5초 고정이다.
- 경직 기여도를 못 받는 승급 전 둔기병은 경험치를 1.9배 받도록 보정했다(`MXP_BLUNT_T0`). calib 기준 0단계 둔기병 경험치 비율 0.57 → 0.74(창병 0.79·검방병 0.76과 비슷).

### 레벨업 속도를 늦춤(베타 1.321)
- 실제로 해 보니 용병 레벨이 너무 빨라 경험치를 `24+1.6×L`에서 `43+2.9×L`로 올렸다(약 1.8배 느림, 15레벨까지 누적 ≈ 950, 60레벨까지 ≈ 6500).
- runbench(스테이지 진행, 용병 6명+60초마다 1명): 스테이지 10 진입 평균 레벨 29 → 17, 최고는 스테이지 8~9에 75 상한(예전 스테이지 7). 4단계 승급(60레벨)은 24명 중 약 1.5명. 앞선 용병이 크게 앞서가는 구조(스노우볼)는 그대로다.

### 레벨업 카드 두 줄 선택(베타 1.323)
- 사용자 제안: 한 장만 고르면 주인공을 키우자니 용병이 죽고 용병을 키우자니 주인공이 약해진다 → 레벨업마다 주인공 카드 하나와 용병 카드 하나를 각각 고른다. 전투 중 고를 틈이 없으니 레벨업은 더 늦게.
- 한 화면에 윗줄(주인공·운영: 규모·주인공 강화·주인공 전설) 3장, 아랫줄(용병: 용병 강화·병종 전설) 3장. `offer`는 6칸이고 고른 줄은 -1(`TUNE.CARD_ROWS`로 끄면 예전 3장 방식). 패널은 0.78배로 줄여 화면을 덜 가린다.
- 속도: 주인공 레벨업 필요 경험치 `12 + 9×(L-1)` → `12 + 20×(L-1)`(약 2.2배). 레벨업 횟수는 같은 경험치에서 약 0.67배가 되고 카드는 두 장씩이라 총 카드 수는 약 1.3배다. 적은 평균 레벨당 체력 +6%→+9%, 피해 +3%→+4.5%로 올려 레벨이 느려진 만큼 따라가게 했다. 수치는 실제 플레이 후 조정한다(시뮬레이션은 하지 않았다).

### 레벨 성장을 합산(기본 수치 증가)으로(베타 1.324)
- 사용자 제안: 용병은 레벨업당 %가 아니라 기본 수치가 오르게 하고, %는 카드로 올린다.
- `levelHp = 1 + LV_HP×레벨`, `levelDmg = 1 + LV_DMG×레벨`(복리 아님), LV_HP 0.034·LV_DMG 0.0225. 60레벨에서 체력 ×3.04·공격 ×2.35(예전 복리는 ×3.3·×2.5), 15레벨 ×1.51·×1.34(예전 ×1.35·×1.26)로 초반이 조금 더 세고 후반은 조금 약하다. 카드 % 보너스는 늘어난 기본값에 곱해지므로 후반으로 갈수록 카드의 절대 효과가 커진다.
- snowbench(스테이지 4, 600초) 1등 몫 36.6%로 이전(약 37%)과 같다.

### 창병 스킬 개편(베타 1.333)
- 사용자 지시: 패시브1 = 2단 찌르기, 액티브2 = 창병 장군의 수비 태세, 패시브3 = 확률로 창을 휘둘러 전방 넓은 범위를 훑는 공격. (패시브1 후보를 고민하던 문제를 이 방향으로 정리. 창 던지기·관통 찌르기·연속 찌르기는 삭제.)
- 2단 찌르기: 찌른 적 전부를 곧바로 한 번 더(공격력 40%). 휩쓸기: 25% 확률로 전방 약 160도·창 사거리 1.25배의 모든 적에게 80%. 수비 태세: 사거리 1.2배 안에 적 2명 이상이면 3초, 0.2초마다 가장 가까운 적 쪽 부채꼴(절반 각 50도)을 공격력 25%로 찌르고 적 화살을 막고 받는 피해 -40%(쿨 15초). 태세 중에도 평소처럼 움직이고 싸운다(장군은 제자리에서 쓰지만 용병은 AI가 자유롭게 움직이므로 묶지 않았다).
- 그림: 새 그림이 필요하다(수비 태세·휩쓸기 아이콘, 휩쓸기·찌르기 이펙트). 지금은 기존 아이콘을 [2단 찌르기←두 번 찌르는 그림, 수비 태세←창과 방패, 휩쓸기←휘어진 호] 순서로 돌려 쓴다. 쓰지 않게 된 `mskill_spear_fly`·`spear_hit`·`mskill_spear_throw` 소리는 보관.
