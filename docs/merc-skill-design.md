# 용병 레벨·승급·스킬 설계안 (초안, 아직 구현 전)

## 1. 큰 구조

- **레벨(연속 성장)**: 경험치가 쌓이면 레벨이 오른다. 레벨 1당 체력·공격이 조금씩 늘고 **골드는 들지 않는다.** 초반에 기여를 많이 한 용병이 바로 강해지는 스노우볼.
- **승급(골드)**: 일정 레벨(안: 5·10·15·20)에 도달하면 골드를 내고 승급한다. 지금의 단계 이름(경기병 → 기마병 …)과 강화 비용을 그대로 승급에 붙인다.
- **승급의 경험치 배율은 없앤다**(`MXP_TIER_BONUS` 0). 앞서가는 이점은 레벨에서만 온다.
- **승급 보상은 능력치가 아니라 스킬**: 1단계 패시브 → 2단계 액티브 → 3단계 패시브 → 4단계 액티브. 기본 체력·공격 보너스(`TIER_HP`·`TIER_DMG`)는 크게 줄이고 레벨이 대신 맡는다.
- **액티브는 자동 발동**: 용병은 AI라서 플레이어가 누르지 않는다. 조건이 맞으면(위협 접근, 적 밀집, 체력 낮음 등) 쿨다운마다 스스로 쓴다. 좌측 용병 목록에 스킬 아이콘과 쿨다운을 표시한다.
- **카드와의 관계**: 지금 카드로 나오는 "독 화살" 같은 병종 전용 효과는 승급 패시브로 옮긴다. 카드는 그 패시브를 **강화**하는 것(독 피해 +%, 둔화 시간 +초)으로 바꾼다.

## 2. 병종별 스킬 (1 패시브 · 2 액티브 · 3 패시브 · 4 액티브)

주인공의 스페이스 스킬(후퇴·돌진·무적·철퇴 투척·방벽·가속)과 겹치지 않게 했다. 수치는 제안값이다.

### 궁병
| 승급 | 종류 | 이름 | 효과 |
|---|---|---|---|
| 1단계 | 패시브 | **독 화살** | 화살이 독을 건다(화살 피해의 일부를 4초에 나눠). 지금 카드 효과를 옮긴 것 |
| 2단계 | 액티브 | **뒤로 점프** | 근접 적이 몸에 붙으면 뒤로 약 150px 뛰어 물러나며 한 발 쏜다(쿨 12초) |
| 3단계 | 패시브 | **얼음 화살** | 화살이 맞은 적을 2초간 둔화(이동 x0.7). 독과 함께 걸린다 |
| 4단계 | 액티브 | **은신** | 3초간 은신(적이 조준하지 못함, 이동 가능). 풀리며 첫 화살이 1.8배(쿨 20초) |

### 기병
| 승급 | 종류 | 이름 | 효과 |
|---|---|---|---|
| 1단계 | 패시브 | **돌파** | 돌격이 적에게 맞아도 속도를 잃지 않고 뚫고 지나가며, 직선상 다음 적 최대 2명에게 돌격 피해의 60% |
| 2단계 | 액티브 | **일제 질주** | 2초간 최고 속도로 달리며 지나치는 적을 밀친다(쿨 14초) |
| 3단계 | 패시브 | **철갑마** | 돌격 중(속도가 붙은 동안)에는 받는 피해 -25% |
| 4단계 | 액티브 | **도약 돌진(잠정, 선택 대기)** | 앞줄 근접 적 너머에 후위 원거리 적이 있으면 크게 뛰어올라 앞줄을 넘어 후위 한가운데에 착지, 주변에 돌격 피해+0.6초 경직(쿨 18초). 후보: B 선풍(포위 탈출 360도 피해+밀침, 16초), C 질풍 연타(4초간 빠졌다 돌아오는 대기 없이 연속 돌격, 20초), D 낙마 구출(쓰러진 아군을 일으켜 부활 -50%, 25초), E 기병 돌격령(5초간 주변 아군 이동·공격 속도 +15%, 22초) |

※ 처음 구상한 박차(처치 시 가속)는 돌파·일제 질주와 겹쳐 뺐다.

## 3. 유지비(급여)

**측정(스테이지 3, 용병 12명 0단계, 300초)**: 급여 없음 403금화, 지금 급여 393금화 → 5분 급여가 약 10금화(수입의 2.5%)라 사실상 없다. 한 명 1단계 강화(궁병 약 54금화)보다 5분 급여 전체가 싸다.

**안**: `급여 = 통솔력 비용 x 기본계수 x (1 + 0.04 x 레벨 + 0.4 x 승급 단계)` 를 45초마다.
- 기본계수 0.6 → 2.0, 레벨 1당 +4%, 승급 1단계당 +40%.
- 예: 0단계 궁병 Lv1 약 2.1금, 2단계 궁병 Lv10 약 13금, 4단계 궁병 Lv20 약 34금(45초당). 24명이 모두 4단계 Lv20이면 약 800금(45초당)으로 크게 부담.
- 못 낸 급여가 쌓이면 용병이 이탈하는 기존 규칙(`unpaid`)은 유지.
- 최종 계수는 실제 플레이 수입(주인공이 싸우는 경우)과 비교해 시뮬레이션으로 정한다.

## 3-1. 카드 정리(결정)

- "독 화살" 카드는 없애지 않고 **"독 강화"**(독 피해 +%, 지속 +초)로 바꾼다. 3단계 얼음 화살에는 **"둔화 강화"** 카드를 둔다. 해당 승급 전에는 그 카드가 나오지 않는다.

## 4. 구현 순서(권장)

1. 벤치(`snowbench`)에 레벨 모델을 붙여 레벨당 성장률을 정한다(지금 강도와 비슷하게).
2. 레벨·승급 구조와 UI(용병 목록·결과 화면)를 먼저 넣는다(스킬 없이 능력치만).
3. 패시브를 병종별로 하나씩 넣고(카드 이관 포함) 시험을 쓴다.
4. 액티브를 병종별로 하나씩 넣는다(자동 발동 AI, 쿨다운 표시, 효과 그림·소리는 에셋 요청).
5. 유지비를 조정한다.
